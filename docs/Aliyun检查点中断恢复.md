# Aliyun 检查点中断恢复

私有原型固定入口为 `homegate-aliyun-read.sh ACCOUNT --repair-checkpoint ORIGINAL_JOB --confirm`。入口、协调器与共用修复工具各有 `aliyun_checkpoint_repair_enabled=false`，环境不能启用。沿用原读取、核对、持久回执和结算门禁，不安装生产入口。

此动作只继续完整检查点的本地发布，不访问云 API、不重发 DNS、不删除原工作目录、不生成终态或归档。成功结果为固定公共报告，含 `checkpoint_repaired:true, write_ready:false`。原活动记录及临时证据仍阻塞写入；后续只读核对只能返回观察，不能认领未知变更。

## 共用发布状态与供应商绑定

复用 `homegate-dns-checkpoint-repair.sh --aliyun-internal repair-checkpoint`。固定别名选择 `HGALIJOURNAL1`、`aliyun-checkpoint.lua`、`HGALICVALID1` 和迁移来源恢复读命令；不接受调用者指定格式、验证器、路径或 URL。Cloudflare 原入口和格式继续独立验证。

允许状态沿用《[DNS检查点修复.md](DNS检查点修复.md)》：

- 首次无 `current` 时，必须有原协议留下的私有 `.next`，仅有完整 `.prepare` 或 `slot-1`；不能有 `slot-2` 或重复候选。准备目录仍在时指针必须为空，槽已发布时指针可为空或严格为 `1\n`。候选已影响计数必须为零。
- 已有合法 `current` 且存在 `.next` 时，候选只能是非当前槽或唯一完整 `.prepare`；指针为空或精确指向非当前槽。只接受同一冻结删除计划的前进检查点，不回退位置，不更换请求、目标集合或原任务。
- 已有合法 `current` 且无准备残留时，只核实并重新同步当前指针及全部现存槽，不选择另一槽替换当前。

每个现存槽先验证 0700/0600、UID、普通文件单链接、固定成员集合、大小及规范帧 SHA256。原身份、boot、代次、账户、任务、保留代清单和上下文哈希全部绑定；不同供应商格式拒绝。原 boot 可与当前不同，但同一回执内全部证据必须属于同一原 boot。

经新的迁移来源绑定私有快照，严格恢复候选及当前上下文。Aliyun 冻结记录包含规范 RecordId、RR、类型、值、TTL、线路、锁定与启用状态；删除位置对应唯一原目标，已影响计数须等于其前方匹配目标数。前进关系要求其余冻结字段完全相同，不能借重新计算帧哈希替换请求、记录 ID 或计数。上下文只允许持久白名单字段，不导出凭据或传输信息。

## 发布和拒绝

沿用 FD6/FD7 共锁并逐 inode 校验。所有状态、文件和前进关系检查完成后，先同步各槽及父目录；完整 `.prepare` 仅重命名到缺失目标槽，再同步目录。空 `.next` 写入唯一目标，同步后原子替换 `current`，最后同步指针和父目录；旧当前槽保留。

任一步失败均保留写屏障。再次恢复仍须明确确认，并重新验证剩余状态；不删除或修补半截指针、缺失清单、损坏上下文、非法当前指针、双槽历史下丢失的当前指针、重复候选、未知成员、链接或权限异常。终态、孤立收集计划等混入时拒绝，不跨维护协议推断状态。

协调器只允许原任务的私有临时目录留在原处，其他孤立目录或原路径的符号链接仍阻塞。内部工具必须借用已验证的共锁；恢复不读取临时请求或云观察来重建检查点。迁移源配置变化时拒绝恢复。

## 边界

缺失完整候选、槽初始化未完成、原临时证据仍在但没有可归属终态等状态继续保留并阻塞，不自动清理未知。当前仅为隔离原型合同；正式授权 UI、业务和生命周期生产接入、真实设备断电/重启、目标 ABI、同提交三包及资源验收另行完成。
