# Cloudflare 未知操作只读核对（r31）

固定 `account --reconcile numeric-job --confirm` 入口用于隔离原型，同启动期未知工作编号只允许无前导零的 2..999999999。必须同时打开原只读、记录和新增 `dns_reconcile_enabled=false` 三层源码门禁；生产配方不安装原型。环境变量不能打开门禁。确认标志只是本隔离 CLI 的明确操作选择，生产官方授权 LuCI 确认界面尚未实现。

## 原证据与配置绑定

沿用 FD6/7、持久配置屏障和独立会话 30 秒监督。持锁后只允许存在指定原孤立目录，任何其他孤立目录直接阻塞，不收集、不删除。原目录 0700、七个槽位均 root/0600/单链接且非符号链接，attempt 必须精确 HGCFATTEMPT1 加 LF。拷贝最大 8 MiB 的原 canonical 上下文到本次单独受限工作目录；原七个文件始终只读保留。

r31 正常记录操作在上下文保存已验证的原始数据请求。核对时使用当前 HGPRIVATE1，重新绑定原账户/代次/DDNS 或证书资源，再逐字段比较 operation/kind/resource/zone/fqdn/type/TTL/value/IPv6 数值身份/显式全删。更换账户、配置代次或范围、缺原请求、未记录 attempted、异常阶段/目标/计数、非 canonical 或不完整上下文均拒绝且不进行 HTTP。r30 旧上下文缺少原请求，保守拒绝，不追认旧快照具备恢复能力。

Token 从当前同代私有快照读取，不复用原上下文中的 Token；原已确认数量、删除目标列表与位置只用于验证证据，不公开这些私有数据。r31 仍不具备持久存储身份和断电回执，不可跨重启/换存储恢复。无法完整证明原请求的记录继续阻塞，不能手工删文件冒充恢复完成。

## 完整只读观察

复用固定 curl/TLS、共享严格 JSON/transport 解析和分页规则：固定配置区域，唯一 ID 必须等于原记录区域 ID；记录固定名称/类型，100 条每页，最多 1000 页/100000 行、64 KiB 单帧、8 MiB 私有上下文、全任务 30 秒。所有页、实际范围和 ID 唯一性通过后才报告，不返回部分观察。理论容量未作目标设备资源峰值验收。

所有请求均 GET；数据驱动器对任何变更方法另行拒绝。创建/更新观察返回 desired-present 或 desired-absent，只表示现在有无相同值（AAAA 数值身份、TXT 精确值）。同值可能由其他调用者创建，因此不认定原写入成功、归属或唯一性，不自动补写。删除对原冻结完整目标 ID 集合观察，返回 planned-targets-absent、planned-targets-present，或同 ID 已有其他值时 conflict；后续新增 ID 不属于原计划，不扩展清理范围，也不删除。

核对成功指完整读取完成；公共结果始终 `effect=unknown`、`reconciliation_required=true`、`retryable=false`，不会给原操作改写成功回执。HTTP/TLS/分页失败返回 incomplete。协调器严格核对 canonical 结果、账户/代次、退出状态和本次 attempt 必须为空。原证据字节保持不变，后续普通 DNS 仍阻塞；核对允许重查，同一共锁防止核对并发。仅清理本次核对目录，异常/被杀残留也继续保守阻塞。
