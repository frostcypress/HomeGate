# DDNS 全批协调与共享采样

固定 root 原型 `homegate-ddns-batch.sh sync --confirm` 对当前明确授权的 1～32 条规则同步执行一批有界工作。批入口、状态工具和单规则入口各有独立 `ddns_batch_enabled=false`；原授权、状态、普通运行及供应商门禁继续适用。生产配方不安装原型，没有新增 Web/RPC、常驻服务、周期任务或自动调度。

## 一次采样与原执行链

整批保有原 frontend/supervisor 共锁，先检查写屏障和未知临时工作，核实当前普通配置与完整授权，再通过原只读状态接口检查各规则。如果全部处于等待、退避、暂停或需核实状态，则不建立采样工作、不调用网络采样或供应商。

至少一个规则可运行时，复用原受监督的 DDNS 计划器，按当前授权集合只采样一次。原始完整计划、意图和当前身份/manifest/授权摘要、boot、批进程身份形成规范私有 HGDDNSBATCH1 帧。采样阶段目录在任何供应商尝试前移除，仅保留已解链接的 0600 普通文件描述符；存在额外成员或清理失败时保留证据并拒绝派发。采样前中断遗留的无绑定工作不会被自动猜测为可清理。

内部状态分支与单规则分支核实直接父进程、固定脚本及参数、批父进程存活身份、同一匿名 FD5、所有权/权限/长度和共锁。调用者不能传地址、域名、路径或请求体。每次派发仍取得当前普通来源的单规则授权快照，重新绑定整份共享计划和全部授权意图，确认来源及授权摘要未变，再产生仅所选规则的计划/意图。不同规则地址不一致、非公开 IPv6、外来配置代、授权变化、额外字段或错误父进程/描述符均拒绝。

单规则入口随后沿用原 HGDDNSWORK2 绑定、供应商监督器、请求检查点与规范终态。没有增加第二套云端写入或恢复协议，子规则不重新采样。批帧不传给云端进程。

## 独立状态与全局写屏障

每条规则复用现有 HGDDNSSTATE1：派发前发布 inflight，结果必须通过原规范回执适配器，再原子发布成功、等待、退避、暂停或 unknown。处于等待/退避/暂停的规则跳过自身，其他可运行规则继续；网络采样失败也分别记入各可运行规则的退避。格式损坏、容量/权限或发布故障不自动清空；不可信结果保留 inflight/暂存及原持久证据，并保守报告整批中断。

持久 DNS 回执仍是全局屏障。前一条规则发生实际变更后，后续规则报告 blocked，不为跑完整批自动收集、归档或退役。unknown 也阻止继续写入，经过再长时间都不自动重试。成功回执须由原明确收尾接口另行处理；后续新批次重新核实状态、授权及来源。当前方案因此允许多条无变更检查，但每次实际变更仍受原单份持久回执协议限制。

公共响应仅有配置代、是否采样、整批保守 effect、write_ready:false 及有界逐规则状态/错误类别/等待时间。它不公开地址、接口、域名、请求体、凭据、批帧或私有摘要。返回码 0 为全部完成，1 为已验证的规则失败，4 为等待/暂停/屏障阻止完成；未能验证结果或本地故障为 7，并保留已验证的部分行，不冒充整批成功。write_ready 始终为 false，批结果不重新授予权限。

正式 CLI/UI、自动调度、生产生命周期、其余冻结业务、目标 SDK/ABI、真实三包和设备/资源验收继续独立待办。此原型只复用本地既有 Linux/BusyBox 与模拟供应商夹具，不代表云账号或目标设备已验收。

## r71 明确收尾扩展

原 `sync --confirm` 的全局回执屏障行为保持。独立门禁的新 `sync --confirm-closeouts` 仅在本次原始成功回执被持久记录并完成既有收尾后继续下一条；详见《DDNS批次明确收尾与持久结果》。r71已通过本地专项，不代表生产启用。

## r111 混合地址来源与独立切片

候选混合授权现在允许AAAA/auto及AAAA/interface的明确规则集合，仍逐项验证引用和凭据。只读预检共用一次有界地址命令；自动来源共用WAN选择，各指定接口分别缓存成功或失败。完整批次重建按auto或interface:设备分组，要求同一来源组的地址、设备及成功/失败一致；指定接口还必须同时匹配配置interface和实际device。完整规范计划匹配后，才能缩窄为一条规则的计划及授权意图，切片不得借用另一来源组的样本。

一个指定接口缺失/无有效地址时，仅该来源组返回network_unavailable；其他规则依各自样本继续。原成功回执和未知尝试仍是全局持久屏障：创建/更新后保留证据，后续规则阻断；只有既有明确收集和退役流程完成后才能继续。混合来源不会自动归档、重试未知尝试或越过配置/启动标识/父进程/匿名描述符绑定。

本阶段回归覆盖四家供应商的三规则不同来源/设备/地址、坏中间规则隔离、真实中间变更及明确收尾后恢复，并核对跨接口样本替换、采样后源接口变化、未知中间尝试阻断。仅临时副本与回环TLS；生产门禁、目标SDK/ABI、真实三包、实机及Lua/RPC混合界面专项仍待验收。实际日志保存在本地，不将协议描述作为通过证据。
