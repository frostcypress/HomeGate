# DDNS 有界前台调度与安全停止原型

r72 本地专项完成，生产门禁关闭，不安装到正式包。

固定 root 入口 `homegate-ddns-schedule.sh run --confirm` 开始一次前台会话。最多准入8轮，准入窗口900秒；已准入的原有有界批次及供应商监督链完成后才返回，不把900秒说成强制中断网络的硬超时。每轮保持共同双锁，重新检查普通配置、完整授权、身份/代次/授权摘要和boot，再消费现有状态等待、退避和暂停。等待时释放共同锁，每秒只读时钟/停止请求，不采样或HTTP；到期重新校验，配置或授权变化就结束。

只调用原 `sync --confirm`。实际 confirmed 变更或unknown即停止并保留原日志、状态及外层证据；不继承批次收尾同意，不自动收集、退役、忘记历史或重试unknown。只读状态不创建会话。

`status` 查询脱敏运行状态，`stop --confirm` 请求协作停止：不再准入下一轮，已准入批次会完成；返回stopping不是宣称子进程已静止。TERM/INT同样只请求停止。没有根据存储PID发信号的路径。状态校验boot、PID出生时间、固定命令及原锁描述符，不把其他进程当作当前会话。

会话位于固定RAM目录 `ddns-schedule`，不可变 HGDDNSSCHEDULE1 绑定配置、授权、启动和拥有者，私有700/600单链接，规范JSON与SHA256帧。单独运行锁防重入，控制锁串行发布停止请求；原共同锁持续覆盖批次及其监督后代。拥有者退出后不自动重启、接管或删除控制证据；`reap --confirm` 仅在会话锁及共同锁可获得、无活跃拥有者、原持久写守卫允许且外层工作已清楚时，删除已识别的RAM控制文件。未知成员、链接或损坏记录拒绝并保留。部分初始化若只留下有效lease.next可明确回收；损坏或不完整记录仍需人工核实。原DNS证据不由此入口删除。

新功能门禁只控制run；status、stop和reap在门禁关闭后仍可缩小活动权限。生产服务启停、开机自启、冷启动恢复和正式授权UI尚未接入。新增4静态/23非root运行，受影响16静态/8运行，2root及11工程检查通过；不代表CI、真实云账户、SDK/ABI、三包或实机验收。

## r112 混合来源调度与接口恢复

混合来源复用既有调度、状态和批次策略，保持900秒会话预算、最多8次准入、按规则退避及协作停止。测试入口新增`python3 scripts/DDNS有界调度回归.py --runtime --mixed-only`；默认回归同时包含原场景和混合场景。业务策略及所有生产/候选门禁不因接合验证改变。

四家供应商的三规则时间线验证：首次无变化；指定接口地址撤销后仅该规则network_unavailable并进入独立retry_wait，其余规则不受影响；恢复地址但未到期限不重新采样/调用供应商；到期重新读取真实样本并清零成功规则的失败计数。每次准入共用一次地址读取，等待期间不扫描网络或HTTP。

指定接口地址变化产生真实更新时，保留原成功回执并停止后续规则，不自动归档。未知中间尝试必须停在reconciliation_required，不重试或清理；配置接口改变则使旧会话绑定失效，在下一次采样前停止。状态策略另验证重试计数上限8、退避上限3600秒及成功后复位。

验证只在临时副本和本地TLS运行，不安装或启动生产服务。目标设备事件接入、Lua/RPC混合入口、真实供应商、完整生产迁移、目标SDK/ABI、真实三包及实机仍须独立验收；详细结果只保存在本地证据文件。

停止命令采用非阻塞控制锁，短暂锁忙可返回退出码4。混合时间线回归只对该明确停止意图在固定5秒内重试；每次仍核对输出、运行者存活和HTTP调用数，超期或其他错误失败，不放宽业务锁或结果断言。
