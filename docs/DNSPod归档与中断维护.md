# DNSPod 归档与中断维护协议

本协议扩展现有私有原型 CLI，不安装进生产包。沿用前端锁、监督锁、配置代和迁移来源绑定；三个维护功能分别由源码常量门禁控制，默认关闭，环境变量不能开启。

## 明确确认的固定入口

入口为 `homegate-dnspod-read.sh ACCOUNT ACTION JOB --confirm`。ACCOUNT 和 JOB 仍使用既有账户、原任务格式；不接受路径、URL、凭据、额外参数或任意供应商。共同要求 DNSPod 入口、恢复、持久回执和结算门禁，另按动作核实维护门禁。

| ACTION | 独立门禁 | 行为 |
|---|---|---|
| `--retire-archive` | `dnspod_retention_enabled` | 明确退役已确认归档，释放一份归档容量 |
| `--repair-terminal` | `dnspod_terminal_repair_enabled` | 重新验证并发布已有完整、绑定正确的终态文件对 |
| `--collect-orphan` | `dnspod_orphan_collection_enabled` | 按持久哈希计划收集原任务的固定临时文件 |

维护动作不调用云 API，也不重试原 DNS 变更。成功公开结果只含固定状态和 `write_ready:false`；终态修复、临时文件收集之后，活动持久记录仍阻塞写入，须另行明确确认归档。退役之后是否可写继续由统一守卫核实，维护回执不代替守卫。

## 一份归档的退役

复用 `homegate-dns-retention.sh --dnspod-internal retire` 和固定目录 `dns-settled`、`dns-retiring`、`dns-retirement`、`dns-retired`。DNSPod 的计划和完成标记格式为 `HGDNPRetire1`；保留 Cloudflare 原格式。读取守卫可验证Cloudflare、Aliyun、DNSPod及华为云四种格式，实际退役只接受自身格式、账户及原任务，不能接管其他供应商的活动计划。

退役前完整验证归档、终态、收集凭据和各文件哈希，持久发布计划后才重命名及逐个删除固定成员。继续执行前先校验所有剩余成员，不递归删除，不移除未知文件、链接或不符哈希的成员。中断的计划、准备文件或退役目录存在时，写入守卫在功能关闭后仍阻塞。已完成的相同确认可重复执行；不会借旧确认删除新归档，也不删除另一笔活动 `dns-operation`。

## 终态文件对的修复

复用共用恢复工具的 `repair-terminal`，只接受原持久检查点和已有终态、绑定元数据。允许完整准备文件对，或一个已发布、另一个尚在准备路径的组合；验证通过后同步、重命名并再次同步。缺失、重复、损坏、身份不符、计数不足或检查点准备残留均拒绝。不能根据当前云观察、临时成功文件或其他槽推断并补造成功。

## 原任务九个临时文件的收集

固定成员为 `request result zones state input context attempt sign-input sign-output`。目录 0700，普通文件 0600、单链接；未知成员、符号链接、硬链接、大小越界、仍存活或被复用的原 PID 均拒绝。不会向历史 PID 发信号。

首次生成计划要求原启动标识一致、已发布终态完整有效、`zones` 与终态逐字节一致、`HGDNPATTEMPT1` 标记准确。经新读取的迁移来源和私有快照复核最后持久检查点；临时请求须与冻结请求完全相同，临时上下文须是同一检查点的 `verify-Action`，最后记录 ID 为1到9007199254740991的规范十进制字符串，并与更新/删除目标一致。当前观察不是归属证明。

`HGDNPOrphan1` 计划绑定原终态元数据、目录设备/ inode 和九个文件 SHA256；计划不存请求、签名或秘密明文。只有计划已发布且重新校验通过，才能允许已删除成员缺失并继续固定成员收集。尚未发布的准备计划必须重新完整绑定，不能借缺失成员推断先前删除成功。签名输入上限 128KiB，原始 SHA256 签名输出上限 32 字节（Aliyun 原 SHA1 上限仍为20字节），其余成员沿用已有上限。

全部临时文件与原目录移除并同步后，删除收集计划；原持久终态和检查点始终保留。工作目录已消失时仍须验证原终态并同步，不能凭空建立成功证据。

## 当前边界

这是隔离开发接口，生产授权 UI 和门禁接入尚待完成。完整检查点发布中断的明确恢复见《[DNSPod检查点中断恢复.md](DNSPod检查点中断恢复.md)》；缺失完整候选或损坏的残留仍保留并阻塞；未知变更继续只读观察，不自动认领、重试或解除屏障。真实设备重启、断电、SDK ABI、三包构建和资源峰值另行验收。
