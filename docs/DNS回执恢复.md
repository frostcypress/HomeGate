# DNS 终态回执与受确认恢复（r33）

复用 r32 持久双槽检查点与 FD6/7。新增协调器和固定恢复工具 `dns_settlement_enabled=false` 门禁，原只读/记录/持久门禁和引擎恢复读门禁也必须具备。环境变量不能启用，生产配方不安装原型。只实现 root 隔离 CLI 的明确选择，官方授权 LuCI 确认/审计界面仍待实施。

## 终态绑定

记录协调器等待原独立会话家族安静、重新验证公共 canonical 结果和实际 attempt 后，才调用固定 settle。仅接受 ok=true/effect=confirmed/无错误、不可重试、无需核对的 created/updated/deleted；账户/代次一致。原持久上下文必须是固定白名单原请求。创建/更新结果对应最后 checkpoint 的 create/update，affected=1；删除必须对应 delete，结果计数等于最后 checkpoint 已确认数+1 且不超过冻结目标数量。unchanged、unknown、失败、部分计数或伪造额外字段不能写为终态。

terminal 保存原 canonical 公共成功报告；HGCFTerminal1 清单另绑定存储身份、原 boot、代次、账户、原工作编号、代 manifest SHA、最后 checkpoint manifest SHA 和 terminal SHA，规范 LF 全帧再 SHA 校验。私有准备文件同步后才分别重命名，再同步回执和存储父目录。失败保留证据与屏障，不输出交付成功；部分终态或残留准备文件不自动修复。成功终态也不自动解除屏障。

## 持久只读核对

固定 `account --reconcile-receipt numeric-original-job --confirm` 从固定 dns-operation/current 选择检查点，验证目录/两个槽的权限、单链接、完整文件名、帧/hash、原账户/编号以及当前存储身份和同一代 manifest。允许原 boot 不同，不要求已丢失的 /var/run 原上下文存在；其他临时孤立工作仍阻塞。

将排除 Token 的原白名单上下文送入本次私有槽，再通过当前 HGPRIVATE1 重新绑定资源/区域/类型/TTL/值/冻结目标，取得当前同代凭据并在原 30 秒监督内执行固定 GET 完整分页。无需安装或下载路由器工具。结果仍是 desired-present/absent 或计划目标存在/消失/冲突的观察，始终 effect unknown，不证明原写入归属或历史成功、不重试变更、不自动解除屏障。读取或绑定失败时不输出部分观察。无有效 current、损坏帧、部分终态或准备残留继续保守阻塞。

## 受确认收集与归档

固定 `account --collect-receipt numeric-original-job --confirm` 要求无任何临时孤立工作，持锁后重新校验已确认 terminal 及其原检查点/代次/身份。未知结果无 terminal，哪怕只读观察满足目标也拒绝收集。仅当前配置代次不变、完整同源证据通过后可继续；CLI 确认不替代未来官方授权边界。

收集保留全部原文件，以固定目录重命名 dns-operation → dns-settled，不递归删除、不扩大到其他路径。先持久发布 HGCFCollection1 collecting 凭据，绑定存储身份与完整 terminal-meta SHA；移动目录并同步父目录后再持久发布 settled。指针准备文件、收集中凭据、悬空链接、归档损坏或缺失均阻塞写入。完成移名前已有完整 collecting 凭据或完成移名后父同步失败时，下一次明确确认可复核后继续；不依据文件“看起来存在”放行。

引擎在每次后续写入验证归档、terminal 和 settled 凭据，并重新 fsync 完成凭据/归档/父目录后才放行；此守卫不受新功能门禁控制。最终 settled 重命名同步不确定时，未成功重新同步前仍阻塞。成功收集可重做而不改归档内容；之后配置代次改变时，普通守卫仍核对原保留代 manifest，不能把旧归档串到新存储。服务/应用既有其他屏障继续有效。

本阶段归档容量固定一份，后续新操作不能覆盖它；可生成下一份活动回执，但再次收集须先完成未来受授权的归档保留/清除方案。当前不自动丢弃历史，不提供 PURGE。部分准备文件和损坏证据仍需后续明确修复流程；不把有限确认收集称为完整冷启动/生命周期迁移。

## 验证与边界

3 新增本地通过；22 新增 Linux 与全部既有回归待当前 Actions。仅可丢弃 loopback HTTPS 数据库、临时 CA、真实 BusyBox/Lua51/jsonc/fsync/rename/curl。验证终态创建与计数/错误绑定、归档原字节保留和写入重新开放、模拟 boot 变化、未知创建/删除的持久只读观察且不收集、哈希/身份/参数/链接异常、终态文件同步及重命名失败、收集凭据/归档发布故障与确认后恢复、完成不确定时重新同步、归档篡改/容量一份/重复收集、孤立工作与关闭门禁。

本地初次静态检查中，测试方法 public 与父夹具 public 字节属性重名，改测试方法名后通过；未作为 Linux 通过证据。模拟 boot/临时目录丢失不是设备重启或断电；完整旧秘密迁移、生产所有读写入口/生命周期/服务启动调度、官方授权恢复页面、SDK ABI/三包、实机和资源仍未完成。下一步受控处理不完整回执/准备残留与归档保留容量，再接生产冷启动与其余完整业务。High、发布前 Ultra 提醒/一次终审/有限优化和 CI 低频等待约定继承；详细记录/当前三 MD/完整 ZIP 仅本地。
