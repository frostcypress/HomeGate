# HTTP/RPC 与 Shell DDNS 授权链路验证

`scripts/rpc-ddns-authority-regressions.py` 验证真实 uhttpd HTTP 会话授权、rpcd 参数类型、候选 ucode/fs 私有请求及真实 Shell 授权文件发布。原生产与候选门禁、路由、ACL 和配方字节不变，只有隔离夹具副本开启；入口为 `scripts/check-ddns-authority.sh`，与 Lua 授权一起归入现有 DDNS 原生授权 UI 专项 CI 组。

六个场景复用 Lua 授权链路的真实后端条件，改经 RPC 执行：单条授权/撤销、完整多规则及窄化替换、确认替换和重放拒绝、源配置漂移/不安全权限、锁忙/不安全预览文件、凭据变化。它们是另一入口的接合证据，不重复宣称新增供应商业务。

另外五个场景检查写入参数类型/未知字段/明确同意、临时 Shell 门禁关闭、只读/匿名/无效/已销毁会话与会话字段注入拒绝、Bearer 与旧式入口共享授权范围、批量请求逐元素授权。HTTP 成功、JSON-RPC 错误、ubus 参数错误及业务拒绝分别核对；无权请求不能进入私有后端，拒绝后配置、授权及预览证据必须保留。

请求目录/文件必须0700/0600并清理。会话、确认码和凭据不写入报告；随机身份相关断言压制正文。夹具复用固定宿主运行时，非root外层映射私有UID0且capabilities全零，只写夹具目录，不改宿主配置或安装软件。状态读取沿用原合同18秒，三个独立namespace分别保留原90秒上限；既有只读专项仍默认6秒。

授权只修改夹具内许可，不调用真实供应商、采样地址、提交任务或启动服务。服务观察仅为初始化所需“停用/无实例”夹具，curl/wget 检出工具不得调用。ready不代表DNS已更新。JS浏览器交互、真实异步提交/维护、生产接管、目标SDK/ABI、三包、实机及资源验收仍待后续；实际本地/CI结果以独立记录为准。

为避免已耗时约22分半的源码组继续累积，r90将两个授权宿主专项移至现有DDNS原生授权UI矩阵组，保留原页面专项并补齐同一固定运行时与隔离前置；源码组保留原会话/只读检查。没有删除检查、增加自动CI或调整25分钟job上限。
