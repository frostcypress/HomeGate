# Shell 核心可行性原型方案

日期：2026-10-11。以 1.3.0-10 为功能基线；用户作废 1.3.1-1，不要求路由器立即降级。目标为 Zyxel NBG7815 的 QWRT R26.3.8，Lua + IPK。本文记录原型实现边界，不代表 A/B 已冻结或已通过真实 Shell 执行验收。

## 已有组件与实现边界

| 业务 | 先复用的目标组件 | 原型需要证明 |
|---|---|---|
| 配置/状态/锁 | UCI、jshn/jsonfilter、ash、flock、logger、procd | JSON 正确转义、错误码、有界输出、事务/锁与过期任务隔离 |
| HTTP/DNS 请求 | curl 7.83.1，OpenSSL 1.1.1x CLI | 每个请求独立 connect/max-time；四家 DNS 认证和错误脱敏；凭据不进 argv/日志 |
| 签名/证书 | 目标 OpenSSL CLI，成熟 ACME 客户端候选 | Aliyun/DNSPod/Huawei 签名能力、DNS-01 记录隔离、JWS/账户持久化、证书导入校验 |
| 持续 HTTPS 代理 | 成熟原生代理组件候选，尚未报告安装 | SNI、WebSocket 等旧合同、可信头、访问名单/CN、热更新与故障隔离 |
| WOL | raw Ethernet 工具候选 + UDP 发送能力 | 同一魔术包的 raw + UDP 两条路径、桥成员、错误/计数；不能只做 UDP |
| 防火墙 | 目标 fw3 + legacy ip6tables/IPv6 NAT | 专属链/钩子、幂等、冷启动退避、防火墙重载恢复；不按 SDK 切换 fw4 |
| 调度/生命周期 | procd、事件、定时执行 | 任务去重、HUP/网络变化语义、停止清理与升级保留；持续代理计入所有进程占用 |

报告中的 BusyBox applet 没有列 timeout，不能假定 BusyBox timeout 可用，也不能把所有外部命令无限等待。curl 使用自己的超时参数；其他任务必须验证目标监督/超时机制。现有 flock 可作原型互斥，但锁文件路径、权限、退出/中断清理与并发验收仍要实现。

本项目 Shell 只控制任务和数据，不自行用循环脚本承担持续 TLS/HTTP 流。代理与 ACME 复用组件必须先列出实际版本、包依赖、可用算法/接口、许可与总占用，不能用“成熟组件”四字代替实现或测试。未经核实不直接安装新版系统基础库。

## 原型实施顺序与证据

1. 先离线实现配置解析、JSON 状态、输入校验和锁的隔离测试，使用合成配置/临时目录；不替换 `/usr/bin/homegate` 或启动现有服务。不同实现用同一 CLI 合同夹具比对。
2. 验证四家 DNS/ACME 候选工具是否覆盖全部操作，特别是 Huawei 认证/zone 发现及 TXT 清理隔离；先使用模拟 HTTP 响应测试签名/解析和错误路径，再用独立测试记录验证联网。
3. 构建代理与 WOL 小型原型，逐条核对旧合同；对新增包/进程做依赖与峰值测量。需要 C 自有模块才能完整覆盖时，记录 Shell/复用方案的具体缺口与测量依据，进入 B 比较。
4. 用目标命令和已核实组件测 M21 空闲/负载/并发，冻结 A/B 与依赖；选择 SDK 时查实际 ELF 的 interpreter/NEEDED/符号，不以 CPU 相同宣称动态库兼容。
5. 完整迁移后再接入生产路径和三包配方。凭据迁移、配置导入预览/回滚、改包名、独立设置页、升级与卸载合同必须同时完成，不能只实现状态/WOL 就发布。

当前已实现 `project/core/prototype/homegate-prototype.sh`：公共配置检查、8 项有界去重 FIFO、私有权限/锁/原子状态文件、任务 token 与代次拒绝。详见同目录 README。3 项静态检查通过；10 项真实 BusyBox 执行回归已在工作流通过。没有新生产 Shell 核心、C 构建、代理/ACME 组件安装、网络业务测试或性能测量。SDK 21.02/24.10 仍是用户允许的候选。当前正式构建门禁继续阻止 Go 对照实现及未核实 SDK。
