# 完整公共 UCI 配置预览

阶段：1.3.0-r14。以 1.3.0-10 的六类配置为基线；没有完成生产凭据迁移或完整 UCI 确认提交/持久回滚，不是可安装发行版。

## 接口与备份范围

`project/luci/lua/luasrc/model/homegate/backup.lua` 是唯一解析、导出、差异规则源。Lua Controller 直接加载；`sync-frontend.py` 将同一文件原样预加载到对照核心的 Lua 桥，不新增 Go 业务实现。Lua/JS 维护页使用同一 HTM，生成 JS 后检查副本一致性。

默认导出 `homegate`、`dns_account`、`ddns_rule`、`certificate`、`web_rule`、`wol_host` 六类的明确公共字段。DNS 凭据/实际账户标识/认证端点、DDNS URL、代理目标 URL、证书/私钥文件、未知字段均不导出。此备份不是完整敏感备份。当前配置超出范围或校验失败时拒绝导出，不能悄悄生成部分备份。

备份头为 `homegate-backup-format: 2`、`plugin: homegate`、`schema: public-uci-v1`、`secrets: omitted` 四条注释。支持上一阶段带格式 1 与 `secrets: omitted` 的公开备份；未标格式的原始 UCI、含秘密/上游字段的旧完整备份以及其他插件文件拒绝导入。未来秘密迁移必须使用明确授权的私有通道，不能把原始凭据作为公开 JSON 预览。

导入只接受命名节、`config`/`option`/仅证书 domains 的 `list`；支持正常单引号、双引号、转义及旧导出的 apostrophe 拼接。它是有界的数据解析器，绝不 source/eval/执行上传内容。拒绝重复/匿名/未知节、重复字段、错误列表、错误元数据、控制字符、无效 UTF-8 字段、越界数字和非法值。恢复候选中总开关、访问控制和所有业务规则关闭。

验证账户/证书/WOL 引用及类型、DDNS 主机和证书域名归属、证书对服务域名的覆盖、重复服务域名/重复 WOL MAC。没有执行 DNS/ACME 请求或验证当前证书文件。来源 URL、上游地址和所有凭据仍需单独补齐；关闭的候选不能当作可运行配置。

协议上限：文件 262144 字节、8192 行、单行 4096 字节、总计 128 个命名节，每业务类型最多 32 个；证书每节 32 域名。普通标签 255 字节、节名 64 字节、访问列表 4096 字节/256 项。数值转为十进制；此上限是本阶段防滥用规则，未冒充实机资源预算。超出范围须调整设计后验证，不能截断导入。

## 服务端与页面行为

原 `config_import` POST 路由保留官方 LuCI POST/授权/CSRF 边界，现在只返回公共字段的服务端差异 JSON，`can_commit=false`。已经移除通过 `uci show` 加字符串检查后直接 cp/mv 覆盖并 reload 的旧路径；即使恶意请求 `mode=apply`，也不会写 UCI、创建导入文件或调用服务。

维护页真实读取用户选择的文件，先检查大小，再使用 URL-encoded POST；Lua 使用 XMLHttpRequest，JS 使用现有最小权限 RPC 写通道和任务 poll/ack，未扩大 ACL。只有配置差异和省略说明进入页面；数据以 textContent 创建表格，不写入 innerHTML。新预览及关闭会使旧响应失效；错误返回清空旧差异，不谎报导入成功。尚不提供确认应用按钮，也没有可重放的“预览即授权”。

服务端当前 UCI 由官方只读游标读取，未知/秘密字段不进入预览；格式错误的已知公共字段标记 `[omitted]`。本阶段预览是读取时的差异，没有生产事务句柄、配置锁下的提交基线或完整私有恢复代次。下一步须在统一写入口下把这个 schema 接到整代存储与凭据迁移，再开放一次性确认及恢复界面。
