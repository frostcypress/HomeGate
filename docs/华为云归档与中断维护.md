# 华为云归档退役与中断维护

本协议仅扩展隔离原型 CLI。入口、协调器和对应工具分别校验源码常量门禁，默认关闭；环境不能开启，生产配方不安装原型。继续使用原前端锁、监督锁、配置代、账户与迁移来源绑定。

## 固定确认入口

`homegate-huaweicloud-read.sh ACCOUNT ACTION ORIGINAL_JOB --confirm` 不接受路径、URL、凭据、额外参数或任意供应商。共同要求原入口、核对、持久回执和终态门禁，另按动作核实独立维护门禁。

| ACTION | 独立门禁 | 行为 |
|---|---|---|
| `--retire-archive` | `huaweicloud_retention_enabled` | 明确退役完整已确认归档，释放一份容量 |
| `--repair-terminal` | `huaweicloud_terminal_repair_enabled` | 继续发布已有完整且绑定正确的终态文件对 |
| `--collect-orphan` | `huaweicloud_orphan_collection_enabled` | 按持久哈希计划收集原任务九个固定临时文件 |

维护不调用云 API，不重试变更。成功结果只含固定状态和 `write_ready:false`；终态修复、临时文件收集后，原活动持久记录仍阻塞写入，须另行明确确认归档。退役回执也不能代替统一写守卫。

## 有界退役

复用固定 `dns-settled`、`dns-retiring`、`dns-retirement` 和 `dns-retired`，华为云独立格式 `HGHWRetire1`。守卫认识四供应商完成格式；实际退役只接受自身格式、账户和原任务，不接管其他供应商计划。

先完整验证原归档、各槽、终态和 settled 凭据，再持久发布只含哈希的计划，才重命名并逐项删除固定成员。续作前校验全部剩余成员；不递归删除、不移除未知文件或链接，不处理不符哈希的成员。计划、准备文件或退役目录存在时，关闭功能后仍阻塞写入。

已完成的同一确认可重复，不借旧确认删除新归档，也不删除另一笔活动 `dns-operation`。中断后必须再次明确确认，完成时保留一份有界完成凭据。

## 仅修复已有完整终态对

复用共享 `repair-terminal`。只接受原检查点及已有规范终态和绑定元数据，允许完整准备文件对，或一份已发布、另一份仍在准备路径的组合。重新核验后同步、重命名、再同步；缺失、重复、损坏、身份不符或检查点准备残留继续保留。

不能从当前云观察、临时成功文件或其他槽推断并补造成功。修复不改原终态或原工作目录的字节。

## 九个固定临时文件

`request result zones state input context attempt sign-input sign-output` 位于原任务目录。目录 0700，普通文件 0600、单链接；未知成员、链接、越界大小、原 PID 存活或被复用均拒绝。不会向历史 PID 发信号。

首次生成计划须同原 boot，已发布终态完整有效，`zones` 与 terminal 字节相同，`HGHWATTEMPT1` 含 LF 共 13 字节。经新来源绑定快照重新恢复最后冻结检查点；原请求相同，临时上下文为相同检查点的 `verify-POST/PUT/DELETE`，除返回 ID 外无额外字段。返回 ID 为 1–128 字节的 ASCII 字母、数字、下划线或连字符；PUT/DELETE 必须等于冻结目标 ID。

上下文完整保留华为云记录集原值及预期消息体；TXT 追加 PUT 和保留其他值的删除 PUT 不可互换、替换目标或放宽绑定。当前观察不作原写归属证明。

`HGHWOrphan1` 只保存原终态元数据绑定、目录设备/inode 和九个文件 SHA256，不保存请求、签名或秘密明文。发布计划后，重新核验才允许已收集成员缺失并继续；准备计划尚未发布时仍须完整绑定。签名输入上限 128KiB，原始 SHA256 输出上限 32 字节；Aliyun 原 SHA1 上限 20 字节及其他供应商规则不变。

逐项移除并同步后才移除原目录和计划；原持久检查点与终态始终保留。若工作目录已消失，仍须验证终态并同步，不能凭空建立成功。

## 边界

完整检查点发布中断的明确恢复见《[华为云检查点中断恢复.md](华为云检查点中断恢复.md)》；缺失、损坏或不可归属 unknown 继续保留并阻塞。生产业务、授权 UI/生命周期、目标 SDK/OpenSSL ABI、同源三包、实机异常及资源峰值另行验收，模拟 boot 变化不代表真实设备断电或重启。
