# 华为云持久检查点与只读核对

隔离原型新增分别关闭的 `huaweicloud_reconcile_enabled=false` 与 `huaweicloud_receipt_enabled=false`。入口、协调器、watchdog、worker各自校验门禁；持久工具另有回执门禁，源码常量不由环境开启。原生产配方不安装原型。

## 固定入口与来源

`homegate-huaweicloud-read.sh ACCOUNT --reconcile ORIGINAL_JOB --confirm` 使用同启动期原工作目录；`--reconcile-receipt` 使用共享持久存储里的华为云检查点。只能观察固定 GET 接口，不接受调用者 URL、方法、记录集 ID 或请求模板，不重发写操作、不修改原证据、不解除写屏障。

复用 FD6/FD7 已持有锁与 namespace、代次、应用屏障校验。恢复读取仅绕过 DNS 写屏障，仍须重新取得配置来源一致的私有快照；账户、资源、配置代、请求与冻结 Zone ID 均重新绑定。其他孤立工作继续阻塞。完整持久检查点可在模拟 boot 变化及临时目录丢失后加载；模拟不是实机断电或重启证据。

## 写前持久化

固定内部入口 `homegate-dns-receipt.sh --huaweicloud-internal checkpoint` 复用共享两槽、`.prepare`、`.next` 与 `current` 发布协议，独立格式 `HGHWJOURNAL1`，标记 `HGHWATTEMPT1`（含 LF 共 13 字节），不接管其他供应商证据。

`HGHWRECORD1` 仅保存白名单上下文、原请求、完整冻结记录集、写方法和准确预期消息体；凭据、签名及 HTTP 配置不持久保存。恢复逐条重建 Zone、ID、名称、类型、TTL、描述、状态、default、原值及比较键，拒绝未知字段或重算后不一致的计划。

从冻结原值重新推导 POST/PUT/DELETE、目标和消息体。新增/更新前缀计数为零；精确删除仍有其他值时只能 PUT 保留这些原值及 TTL/描述，最后一个值移除才 DELETE。删除位置必须匹配冻结目标，已确认数必须等于之前匹配记录集数。后续检查点只允许同一冻结计划向前推进，允许相邻目标分别采用 PUT 和 DELETE。

每次先保存工作上下文和原尝试标记，持久化完整准备槽、文件与目录同步后发布非当前槽，再持久发布唯一指针。绑定存储身份、原 boot、配置代清单、账户、任务、上下文 SHA256 和清单帧 SHA256。工具成功返回后才发该次变更；同步或重命名失败不发该次写，保留屏障和已有当前槽。第三次发布复用非当前槽。

## 观察语义

完整查询唯一 ACTIVE 公网 Zone，要求 ID 与冻结计划一致；完整读取未过滤记录集列表后才给结论。后页错误、分页漂移或畸形响应返回 incomplete，不输出部分判断。

upsert 观察 desired-present / desired-absent，非 ACTIVE 或默认匹配返回 conflict。删除仅观察冻结匹配目标：原完整值仍在表示 planned-targets-present；精确保留计划已达成或原本应整集删除的 ID 消失表示 planned-targets-absent。其他值、TTL、描述、名称或状态变化返回 conflict；原本应该保留其他值却整个 ID 消失也返回 conflict。值列表按规范比较键的多重集合比较，保留重复值语义。新增 ID 不作原操作归属证明。

所有观察维持 `effect:unknown`、`retryable:false`、`reconciliation_required:true`。即使目标当前存在或已移除，也不能证明原写归属或结算成功；原持久和同启动期字节保持不变，父协调器再次验证规范公共结果。

## 边界

成功变更仍保留持久屏障；原成功终态及明确确认归档见《[华为云终态与确认归档.md](华为云终态与确认归档.md)》。有界退役与中断维护见《[华为云归档与中断维护.md](华为云归档与中断维护.md)》。残缺准备槽或指针不自动修复、丢弃或绕过。关闭可选门禁不能解除已有证据的保护。

仅适配普通 v2 记录集、北京四官方端点、永久 AK/SK、ASCII/A-label 和 API 默认企业项目范围。详情读取与写提交之间仍无条件写并发保证。正式业务、授权 UI/生命周期、目标 SDK/OpenSSL ABI、同源三包、实机和资源峰值分别待验收。
