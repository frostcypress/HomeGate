# 华为云检查点发布中断恢复

隔离原型固定入口为 `homegate-huaweicloud-read.sh ACCOUNT --repair-checkpoint ORIGINAL_JOB --confirm`。入口、协调器和共用修复工具各有独立关闭的 `huaweicloud_checkpoint_repair_enabled=false`，环境不能启用。沿用原读取、核对、持久回执和终态门禁，生产配方不安装原型。

只继续已有完整检查点的本地发布，不访问云 API、不重发 DNS、不删除原工作、不生成终态或归档。成功结果仅为 `checkpoint_repaired:true, write_ready:false`；原活动记录及临时证据仍阻塞写入，后续观察仍 unknown，不能认领原变更。

## 状态与绑定

复用固定 `homegate-dns-checkpoint-repair.sh --huaweicloud-internal repair-checkpoint`，选择 `HGHWJOURNAL1`、`huaweicloud-checkpoint.lua`、`HGHWCVALID1` 和迁移来源恢复读取。调用者不能指定格式、验证器、路径或 URL。

- 无 `current` 时，必须有原协议留下的私有 `.next`，仅接受唯一完整 `.prepare` 或 `slot-1`；不能有 `slot-2` 或重复候选。准备目录仍在时指针必须为空；槽已发布时指针可为空或严格为 `1\n`。初始已确认计数必须为零。
- 有合法 `current` 且有 `.next` 时，只接受非当前槽或唯一完整 `.prepare`，指针为空或准确指向非当前槽；候选须为同一冻结删除计划的前进检查点。
- 有合法 `current` 且无准备残留时，只重新核验并同步当前指针及所有现存槽，不从另一槽推断或替换当前。此 current 模式不强行要求一次前进。

每个现存槽检查 0700/0600、UID、单链接普通文件、固定成员、大小及规范帧 SHA256。存储身份、原 boot、配置代、账户、任务、保留代清单与上下文哈希必须一致。原 boot 可以与当前不同，但同一回执所有证据必须属于同一原 boot。不同供应商格式拒绝。

经新来源绑定私有快照重新恢复候选及当前上下文。华为云冻结证据包含 Zone ID、请求、完整记录集原值、比较键、TTL、描述、状态、default，以及准确预期方法、目标和消息体；记录 ID 仅允许 1–128 字节 ASCII 字母、数字、下划线或连字符。未知字段和不一致的重建结果拒绝。

删除位置和已确认前缀计数重新计算。前进时允许前一目标以 PUT 保留其他值、后一目标以 DELETE 删除整集；方法、目标、预期体仍由各自冻结记录重算，其余请求和完整原计划必须相同。不得借重算哈希更换请求、ID、TTL、描述、状态、原值或前缀。TXT 追加 PUT 的其他原值及预期体也必须完整绑定。

## 发布与拒绝

借用 FD6/FD7 共锁并核对 inode，先完成全部文件及前进关系校验，再同步各槽和父目录。唯一完整 `.prepare` 只重命名到缺失目标槽并同步；空 `.next` 写入唯一目标，同步后原子替换 `current`，最后同步指针与父目录。旧当前槽保留。

失败保留屏障，再次恢复须明确确认并重新核实状态。不删除或补造半截指针、缺清单、损坏上下文、非法 current、双槽历史下缺失的 current、重复候选、未知成员、链接或错误权限。终态或孤立收集计划混入时拒绝，不跨维护协议推断。

只允许原任务的私有工作目录留在原处；其他孤立目录和原路径符号链接继续阻塞。内部工具没有已验证的借用锁不能修改。恢复不从临时请求或云观察重建检查点；迁移来源变化时拒绝。

## 边界

缺失完整候选、初始化未完成、损坏或不可归属 unknown 仍保留并阻塞，不自动清理。该合同仅为本地隔离原型；完整业务和授权 UI/生命周期生产接入、目标 SDK/OpenSSL ABI、同源三包、真实设备断电重启及资源峰值分别待验收。
