# 华为云私有认证与公网域名发现

这是隔离 CLI 原型，不安装生产包。固定入口为 `homegate-huaweicloud-read.sh ACCOUNT` 或 `ACCOUNT --zones`；入口、共用协调器、watchdog、worker 的独立源码常量门禁默认关闭，环境变量不能开启。读取模式不接收写请求体、调用者路径或端点参数。独立关闭的记录模式见《[华为云记录操作.md](华为云记录操作.md)》。

## 范围及官方依据

按华为云[公网域名列表 API](https://support.huaweicloud.com/api-dns/dns_api_62003.html)，只请求 `GET /v2/zones`、`type=public`，使用 limit/offset 完整分页，不跟随响应中的链接。该接口说明公网域名为全局资源，并建议选择北京四；[官方 SDK 地区定义](https://github.com/huaweicloud/huaweicloud-sdk-python-v3/blob/master/huaweicloud-sdk-dns/huaweicloudsdkdns/v2/region/dns_region.py)列出 `dns.cn-north-4.myhuaweicloud.com`。

本步端点仅接受私有配置中的 `https://dns.cn-north-4.myhuaweicloud.com`（可有末尾单个斜线），没有默认回退。其他地区、旧别名、自定义代理、HTTP、端口、用户信息、额外路径、查询和片段均拒绝，不能声称全部华为云区域已适配。企业项目范围沿用接口默认值和账号授权，不宣称跨全部企业项目发现。域名接受规范 ASCII/A-label；API直接返回未经转换的中文域名时拒绝，IDNA转换仍待核实，不以部分名单冒充成功。

## 来源绑定与私有签名

沿用既有迁移来源绑定、私有快照、前端锁/监督锁、工作族期限和原孤立目录屏障。凭据从同账户同配置代私有快照的 `huaweicloud.ACCOUNT.key_id/secret/account_id/endpoint` 读取，不从参数或环境接收。AK须为非空受限字符，账号ID须32位小写十六进制，SK最大4096字节；缺失、格式错误和不支持的端点在HTTP前拒绝。

依据[签名机制](https://support.huaweicloud.com/devg-apisign/api-sign-algorithm-001.html)实现 SDK-HMAC-SHA256：规范URI补末尾斜线，查询按编码后键排序，签名头固定为 content-type、host、x-domain-id、x-sdk-date；X-Sdk-Date使用UTC，消息体为空。[签名前置信息](https://support.huaweicloud.com/devg-apisign/api-sign-provide-start.html)说明全局服务的账号头；[DNS鉴权说明](https://support.huaweicloud.com/api-dns/dns_api_30003.html)支持AK/SK。本步仅永久AK/SK，不实现临时凭据的X-Security-Token。

复用已有纯编码和HMAC填充；所有SHA256由固定OpenSSL经私有FD8/9执行，不把SK交给-hmac、-macopt、argv或环境。固定参数只含dgst/-sha256/-binary。curl配置和签名中间字节位于0700工作目录的六个0600单链接文件，curl只通过私有配置文件读取签名头。curl/OpenSSL子进程关闭不需要的签名和锁FD，不输出响应原文、账号ID、AK/SK或供应商错误消息。

## 传输、分页与公共回执

仅固定HTTPS源、CA校验、3秒连接/10秒请求期限，禁用代理/用户curl配置，不跟随重定向或自动重试。原有独立watchdog控制整个工作族；调用者消失不能留下无限请求，也不能自动删除未确认孤立目录。

认证检查只读一条并核实响应结构，表示当前账号可执行该读取，不代表有写权限。域名发现每页100，最多1000页/100000条、单响应64KiB、规范公共结果64KiB以内。严格要求zones数组、metadata对象和整数总数，每个成员为合法公网域名。总数变化、重复资源ID、空/短缺页、错误后页、越界或畸形数据均返回失败和空名单；只有完成全部页才排序/按名字去重输出。资源ID、额外元数据及links不进入公共名单。

公共回执固定provider/account/configuration_revision/check_scope，错误仅固定分类和白名单代码；未知代码归为provider_rejected，原消息丢弃。协调器在工作族静止后重新核对原始规范回执、账户、配置代和check/zones范围，再只收集本次分配的固定工作文件。关闭门禁不会绕过已有的写入和孤立证据屏障。

## 验证边界

本地测试使用独立Python签名计算和真实curl/loopback TLS，固定生产主机参与签名，只有夹具副本的连接地址被替换。覆盖UTC边界、长密钥、端点拒绝、分页和错误脱敏、来源/共锁、参数/环境/FD隐私、工作族期限。没有真实云账户或路由器操作。

尚无华为云记录变更、持久恢复、生产授权UI/生命周期、目标OpenSSL1.1.1/SDK ABI、同源真实三包、设备重启断电和资源峰值验收。宿主OpenSSL3不能替代目标兼容性依据。
