# 华为云终态与明确确认归档

隔离原型新增 `huaweicloud_settlement_enabled=false`，入口、共用协调器、恢复工具分别关闭；原读取、记录、核对及持久回执门禁仍须满足。环境不能启用，生产配方不安装原型，没有正式 LuCI 确认入口。

## 仅原次完整成功可落终态

协调器等待独立工作族静止，验证规范结果、实际尝试标记、账户及配置代后，才调用固定内部 settle。只接受原次 `ok:true`、`effect:confirmed`、不可重试且无需核对的 created / updated / deleted。

最后持久检查点须与结果匹配：POST 新建为 created，AAAA 的 PUT 为 updated，TXT 追加的 PUT 为 created，计数均为一。删除可能为保留其他值的 PUT，也可能为最后值移除的 DELETE；须对应最后冻结匹配目标，最终记录集计数等于原前缀加一且覆盖全部冻结匹配目标。PUT 保留原值、TTL、描述的预期体和 DELETE 的空体继续受检查点绑定约束。

unknown、部分删除、失败、unchanged 或只读观察均不能落终态；观察到期望值或删除结果不能补造原写成功，也不重发变更。

terminal 保存原规范成功字节。独立 `HGHWTerminal1` 绑定存储身份、原 boot、账户、配置代、原任务、保留代清单、最后检查点清单及终态 SHA256，再校验 LF 规范帧 SHA256。settle 必须仍处于原 boot，不能重启后从现状重建。

终态准备文件对先同步，再分别重命名，最后同步回执及存储父目录。任一步失败不返回成功，保留屏障和原证据。完整终态仍保留活动写屏障。

## 明确确认归档

固定入口 `homegate-huaweicloud-read.sh ACCOUNT --collect-receipt ORIGINAL_JOB --confirm`，不接收路径、URL 或消息体。要求原工作族已静止且无孤立临时目录，重新核实来源、账户、配置代、原任务及完整检查点与终态。缺终态、来源变化、损坏、错误绑定、链接、权限错误或准备残留均拒绝。

复用 `dns-operation`、`dns-settled`、`dns-collection` 和已持有锁；独立 `HGHWJOURNAL1` / `HGHWTerminal1` / `HGHWCollection1` 不能接管其他供应商证据。

先持久发布绑定 terminal-meta SHA256 的 collecting 凭据，再将活动目录原子移动为归档并同步父目录，最后持久发布 settled。全部原字节保留，不递归删除。已发布 collecting 后的 rename 或父目录同步中断，可以在下一次明确确认并重新核实实际状态后续作；不自动清理残缺凭据。已完成的重复确认不修改归档。

## 写守卫与当前边界

写守卫根据检查点格式选择固定校验器；关闭华为云功能门禁后，仍核验归档、所有槽、身份及历史代清单、终态与 settled 凭据并重新同步。后续配置变化也保留原历史代绑定，损坏继续阻塞。

完整终态允许只读核对，但观察仍 unknown、不结算、不解除屏障。归档容量一份，新活动不能覆盖旧归档。归档退役、已有完整终态对修复和固定临时文件收集见《[华为云归档与中断维护.md](华为云归档与中断维护.md)》。完整检查点发布中断恢复见《[华为云检查点中断恢复.md](华为云检查点中断恢复.md)》；缺失或不可归属证据继续保留。

仅为隔离 root CLI 合同。北京四端点、永久 AK/SK、ASCII/A-label、普通 v2 记录集和无条件写并发保证等边界仍在。目标 SDK/OpenSSL ABI、同源三包、正式业务/授权 UI/生命周期、路由器功能及断电重启、资源峰值仍须分别验收。
