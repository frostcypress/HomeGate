# 华为云配置绑定 AAAA/TXT 记录集操作

这是隔离原型合同。固定入口 `homegate-huaweicloud-read.sh ACCOUNT --records` 从私有FD读取一行规范JSON，沿用 `cloudflare-record-plan.lua` 的账户、配置代、资源及域名绑定；不接收端点、URL、记录集ID或任意请求模板。入口、协调器、watchdog、worker四个 `huaweicloud_records_enabled=false` 门禁独立关闭。仍使用已核实的北京四端点、永久AK/SK、ASCII/A-label与默认企业项目范围，生产配方不安装原型。

## 接口与计划

采用官方v2[创建](https://support.huaweicloud.com/api-dns/CreateRecordSet.html)、[列表](https://support.huaweicloud.com/api-dns/ListRecordSetsByZone.html)、[详情](https://support.huaweicloud.com/api-dns/ShowRecordSet.html)、[修改](https://support.huaweicloud.com/api-dns/UpdateRecordSet.html)、[删除](https://support.huaweicloud.com/api-dns/DeleteRecordSet.html)接口。方法/路径只由固定代码和已验证资源ID构成。签名覆盖实际方法、补斜线的规范路径、排序查询和准确JSON消息体；保留私有OpenSSL FD和固定curl配置，不把密钥或请求内容写入参数/环境。

DDNS仅AAAA，绑定已配置规则、IPv6和TTL；DNS-01仅TXT，绑定ACME证书与已配置域名。规范输入最多4096字节，未知字段、无关账户/资源、路径、非法IPv6、非允许挑战或没有明确all的空值删除在HTTP前拒绝。TXT挑战不得指定all。

先完整解析配置域名对应的公网Zone列表，要求唯一、ACTIVE；没有或重复匹配拒绝。再按未过滤的整个Zone记录集列表完整分页，完成后才选择同主机/类型目标。列表和总数固定一致，每页100、最多1000页/100000项；重复ID、后页错误、错Zone、空/短缺页、畸形数组和越界均失败，不能使用部分计划。

共享严格JSON解析器额外保存数组长度与数组中的容器形状；记录集及其records数组逐项核实，不能因Lua丢失null元素而接受残缺值列表。单响应64KiB，私有冻结上下文最多8MiB，请求JSON最多32KiB、私有curl配置最多64KiB，仍受工作族总期限限制。

## 记录集与值语义

采用v2普通记录集，验证ID、Zone/FQDN/类型、TTL、描述、状态、default及完整值数组。系统默认、非ACTIVE、线路/权重/别名等未适配记录集拒绝变更。写前重新获取目标详情并与冻结原值、TTL、描述及状态比较；不符则不发变更。尚无条件写/ETag接口保证，详情核对与提交之间的并发不能视为已解决，后续生产集成须另行验收。

- AAAA已有等价地址时不写；否则沿用1.3.0-10行为，更新所选第一个记录集为本次地址，其他记录集不动。指定地址删除时按IPv6等价比较，仅移除匹配值，其余值/TTL/描述保留；明确all才删除该主机/类型下全部匹配记录集。
- TXT已有等价挑战不写；新增只追加本次值，保留其他原值字节及已有TTL/描述。清理只移除本次挑战；仍有其他值时PUT保留列表，最后一个值移除后才DELETE记录集。affected统计已确认变更的记录集数，不是值数量。
- 按[官方TXT规则](https://support.huaweicloud.com/usermanual-dns/dns_usermanual_0012.html)解析双引号字符串及分段，支持引号/反斜线转义，按逻辑拼接值比较；新值按255字节分段并编码，其他值不重写。为兼容基线保留无引号的简单ASCII值；不支持的转义、非法或超限内容拒绝，不猜测转换。

## 先留原证据，再发变更

冻结输入、Zone/记录集计划和阶段写入同次私有上下文HGHWRECORD1；每次变更前先写 `HGHWATTEMPT1` 标记，再请求HTTP。成功后的verify阶段记录返回ID和预期内容。该阶段为九个固定0600单链接工作文件，目录0700；凭据仍在私有快照，公共结果不含记录值、ID、域名或账号ID。

官方创建/更新/删除返回202，不能把接受或PENDING当成功。本步不自动重发变更：先验证原响应身份和值，再独立回读ACTIVE、完整值列表/TTL/描述；DELETE则完整重新列出并确认原ID消失。仍在PENDING、索引未更新、缺回执、错误回读、超时或后续删除失败均返回unknown、retryable:false，保留原上下文和已确认前缀计数。

确认的是API中记录集状态，不能代替全网DNS传播或设备验收。当前无持续轮询；一次回读仍未确认时保留unknown，不用重试创建来“修复”异步状态。

协调器等工作族静止后，重验规范公共结果、原账户/配置代、实际attempt标记与计数。无写必须unchanged/none/0；confirmed必须存在本次真实标记，创建/更新计数为1，未知不得可重试。空attempt文件按未尝试处理。正常确认后只收集本次固定工作文件；unknown保留九文件并阻止后续DNS读写，不能被Cloudflare回执门禁套用。独立期限和调用者丢失合同继续适用。

## 边界

独立关闭的持久检查点与只读核对见《[华为云恢复与持久回执.md](华为云恢复与持久回执.md)》。未启用回执时unknown仍仅在同启动期目录；启用时成功也保留持久屏障；原成功终态与明确确认归档见《[华为云终态与确认归档.md](华为云终态与确认归档.md)》，有界退役和中断维护见《[华为云归档与中断维护.md](华为云归档与中断维护.md)》。模拟恢复不作实机断电证据。生产业务、授权UI/生命周期、其他端点/IDNA、目标SDK/OpenSSL ABI、同源三包、实机及资源预算仍待完成。
