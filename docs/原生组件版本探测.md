# 原生组件临时版本探测

用户手动报告已确认目标有sha256sum，独立timeout和BusyBox timeout都不存在。探测器从r173起随临时tar附带静态AArch64 `probe-run`，不依赖目标动态加载器/系统库，不安装为系统工具，不替换BusyBox或libc。使用既有24.10.6交叉编译器、`-static -Os -Wall -Wextra -Werror`构建；原始musl和GCC运行时许可随临时包保留。源代码为`scripts/native-component-probe.c`。

执行器只接受`--nginx`或`--wol`，分别调用当前目录的`nginx -V`或`wol-send --version`，不能传任意程序或参数。每次限制10秒，使用单调时钟；子进程先创建专用进程组，父进程以WNOWAIT观察退出，先清理本次组再回收直接子进程，避免回收后PID复用导致误杀。父进程收到SIGINT/SIGTERM时同样清理；直接子进程设置父进程死亡信号。先重置继承的SIGCHLD忽略状态，确保未回收子进程的身份仍由执行器持有。版本分支不会启动服务或发送WOL，执行器不是通用业务命令监督器。

脚本仅用目标已有sha256sum核对所有包内文件（包括执行器），清除动态库与OpenSSL配置环境变量，再执行固定版本调用。缺sha256sum/执行器、校验失败等情况拒绝，不安装任何工具、不取消超时。退出码保留组件原值，超时124、执行器错误125、子进程准备失败126、exec失败127。脚本整体任一调用失败返回1，原始码分别写入报告。库加载/功能/worker权限/资源验收相互独立，两个版本调用通过也不代表正式ABI或产品验收。

宿主回归`scripts/native-component-probe-regressions.py`在既有非特权UID下，编译同一C源码，验证固定参数、退出码/信号码、缺组件、真实10秒超时与进程组清理、直接子进程退出清理、父进程中断、继承SIGCHLD忽略等边界。目标AArch64执行器只做静态ELF核对，代理不在路由器执行；实机输出由用户手动提供并单独归档。
