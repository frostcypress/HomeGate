# 固定服务预检、启停与观察恢复

r27 为未安装的持久原型新增 `--persistent service-apply <内部句柄>` 和 `--persistent service-recover`。两个入口只能由源码中的固定门禁启用，不能由环境、请求路径、动作或状态布尔值开启；所有生产门禁保持关闭。仅绑定 HGAPPLICATION3 的同 boot、存储身份、代次、原配置摘要与令牌，不接受 HGAPPLICATION1/2 作为实际服务上下文。

协调器在同一 FD6 共享写锁、FD7 监督锁和 FD9 配置锁内验证并执行。预检核实不可变代次、已绑定的当前源文件、固定 init/rc.common/ubus/uci/homegate 可执行文件的所有者/权限/单链接，以及固定 `uci -q show homegate` 的返回码。预检属于配置解析和依赖检查，不是四家 DNS、ACME、代理、防火墙或凭据健康检查；没有用旧 Go 核心 `check` 的运行状态报告冒充新核心预检。包升级状态标记存在时拒绝操作。

应用先观察开机/运行状态，开机意图必须匹配日志；原运行时仅调用固定 `/etc/init.d/homegate stop`。再次真实观察静止后才调用既有原子配置投影并同步文件/父目录；新导入配置保持停用，绝不调用 enable/disable/restart/reload。最后观察配置摘要、开机状态及停止状态，核实通过才写终端日志并关闭持久屏障。返回 `business_applied=false`，不把停服和配置投影称为完整业务应用。

恢复明确执行：先验证原上下文及文件，再恢复基线指针，按需停服、发布原始受限 source.conf、预检；仅原先运行时调用 start，即使原开机启用为 0，也保留这种独立状态。原先停止的服务保持停止。固定观察器核实原开机和运行状态后才 ACK；命令返回 0 但观察不符仍失败。终端日志清理重试也须重新核实配置及服务状态，不直接猜测完成。

动作复用已有独立 setsid 看门人，固定五秒期限加一秒终止宽限；保留共享 FD6/监督 FD7 至动作族静止，动作子进程关闭这些锁、FD9 和私有输出。协调器 SIGKILL 后遗留普通动作族仍受期限约束且持有写屏障；动作结束后未完成日志仍要求明确恢复。只向当前看门人自己的活进程组发信号，不按保存的服务 PID 发信号。procd 管理的服务由固定 init stop 处理，不由工作族扫描冒充停止。系统 I/O 永久不响应、双重杀死看门人、恶意逃逸进程、闪存掉电与冷启动未获证明；未知或失败保留屏障，不自动修复外来源文件/破损日志/遗留 .work 文件。

动作端清除 init 调试、包升级路径、Lua 和旧核心的路径环境覆盖；固定 PATH。root 管理之外的独立写程序仍可能更改系统，因此所有旧生产写入口、包生命周期和新业务读取端完成共锁与持久迁移前，不能打开门禁。旧原配置/秘密不删除，证书文件树未迁移，当前无三包。

[OpenWrt 21.02 rc.common](https://github.com/openwrt/openwrt/blob/openwrt-21.02/package/base-files/files/etc/rc.common) 区分 enable/disable 与 start/stop，procd stop 调用服务清理和实例删除；[procd Shell 接口](https://github.com/openwrt/openwrt/blob/openwrt-21.02/package/system/procd/files/procd.sh) 描述实例与服务锁。它们是接口依据，不能证明 QWRT 定制实现一致。

新增 20 项 Linux、3 项本地检查覆盖四独立状态、真实 fixture 进程启停/官方 UCI 解析、非零命令、虚假退出成功、原始秘密恢复、源变动、错 boot/开机意图、参数/日志格式、依赖/包标记、共锁借用、环境隔离、调用者死亡和终端清理观察。20 项 Linux 及全部既有回归通过[Actions](https://github.com/frostcypress/HomeGate/actions/runs/38373836096)；实际源码 `2d7ce3fd3fa8689bd566505a24f86fc69310e6d8`，58 个关键文件逐字节核对，SDK/发布跳过。路径/UID/gate 仅在私有复制中替换；init/ubus 是明确夹具，BusyBox/Lua/jsonc/UCI/进程/锁/fsync/rename/SIGKILL 真实执行；没有实际 procd 或 QWRT 服务启停验收。
