# 固定服务采样适配器

1.3.0-r21 接入 `--public-uci commit-apply-observed <确认句柄>`。它先取得原有配置/监督 flock、验证预览，再通过固定只读适配器采样；调用者不能提供开机/运行状态、命令或路径。两次稳定采样通过后再次验证预览，并将两项原意图及当前 boot 写入 HGAPPLICATION2，随后发布隔离配置代次。采样失败不会分配候选或发布日志/指针，返回 7 并保留预览。

原开机启用状态来自固定 `/etc/init.d/homegate enabled`，运行状态来自 `/sbin/ubus -t 2 -S call service list '{"name":"homegate","verbose":true}'`。rc.common 的 enabled 检查开机 S 链接，与服务实例运行状态独立；[OpenWrt 21.02 rc.common](https://github.com/openwrt/openwrt/blob/openwrt-21.02/package/base-files/files/etc/rc.common) 和 [procd 实例字段](https://github.com/openwrt/procd/blob/master/service/instance.c) 是接口参考，不能据此宣称 QWRT 定制实现已经核实。

解析复用设备已有 `luci.jsonc`，只输出两项状态和 boot 的短私有帧；ubus 的原始 JSON、环境变量、PID/命令行不写日志或公开状态。JSON 上限 64 KiB，官方增量解析器要求完整单文档及空白尾部；只接受 HomeGate 单实例且固定 `/usr/bin/homegate daemon` 命令。未知字段不会回显；重复键语义沿用 json-c，因此只能信任固定本机 root/procd 接口，不能将此解析器用于外部上传 JSON。空服务只接受已知 `{}`、`{"homegate":{}}` 和 autostart=false 空形式；实例、状态或 PID 缺失/类型错误、额外实例及不支持的定制结构均失败关闭。

运行实例还须与真实 `/proc` 的完整 argv 匹配，PID/birth 前后稳定且无第二个同命令进程；手动启动但未登记 procd、旧 PID、同名无关程序或僵尸都不能默认为正确状态。进程遍历最多 4096 项、列表 64 KiB、每项元数据 8 KiB。两次采样的开机启用、运行及瞬时 PID/birth 身份必须一致，boot 不变；原配置 enabled 不参与推算。

固定只读采样器在独立 setsid 会话内运行，五秒看门期限加一秒终止宽限，调用者 SIGKILL 后仍会约束普通子孙；只有确认工作进程成功、工作族静止才接受私有帧。信号仅发送给当前活会话领导者自身的组，不向状态中记录的服务 PID 发信号。辅助读取 `/proc` 和 Lua 执行依赖正常响应，系统卡死/不响应 I/O、逃逸会话的第三方进程和双重杀死看门人未获证明；这里只允许受信任固定只读命令。采样子进程关闭继承的写锁，协调器持锁直到采样验证/提交；协调器死亡后遗留的只读工作端不能继续发布配置。

本轮新增 13 项 Linux 采样、2 项静态及全部既有回归通过[Actions](https://github.com/frostcypress/HomeGate/actions/runs/38209902644)，实际源码 `f8bb5bed0bb7030c1613727012cab5d534997709`，39 个关键文件逐字节核对；SDK/发布跳过。init/ubus 端点为明确夹具，夹具复制代码后只替换固定路径与所需 UID；生产源码没有可由环境指定这些端点的测试后门。BusyBox、官方 LuCI jsonc、真实 Linux /proc、进程、锁、超时及调用者终止均真实执行；不是 QWRT 路由器实测或真正的 procd 服务启停测试。CI 编译未经修改的 [LuCI jsonc 源码](https://github.com/openwrt/luci/blob/e4c46338b196e486a88b1a75b78e283708c82bc4/libs/luci-lib-jsonc/src/jsonc.c)，核对 SHA256 后使用宿主库链接；这不证明设备 JSON-C ABI 或 SDK 匹配。

这个入口仍是未安装的原型。隔离代次未成为 `/etc/config/homegate` 的生产来源，直接调用现有 init 会使用旧配置，故本版尚未接入 start/stop/reload、双状态真实观察 ACK 或生产 Web 写路由。r20 手工状态与 ACK 入口仅保留协议实验用途；生产适配器未来必须内部采样并监督动作，不能让 Web 提供观察值。不同 boot 的非终端日志仍保留冷启动屏障。完整 Shell/C 新核心、生产共锁/持久路径、实际业务、SDK 三包及设备验收仍待完成。
