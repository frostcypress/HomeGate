# 六类公共配置与凭据代次事务

阶段：1.3.0-r15。沿用同一 `homegate-config-prototype.sh` 存储引擎，新增 `--public-uci` 模式，不复制另一套事务算法。生产配方不安装实验目录，不读写 `/etc/config/homegate`；Lua/JS 维护页仍只预览。旧核心及保存入口尚未遵守统一锁，因此当前不能安全开放生产确认按钮。

## 数据与凭据

`config-codec.lua` 在固定内部路径加载 LuCI 的 `backup.lua`。六类 `public-uci-v1` 配置使用同一字段/引用/上限规则，规范化为真实 UCI 文本，重新解析生成结果以检查展开后的大小和行长度。所有恢复候选的服务及访问控制关闭。Shell 不 source/eval 上传内容；Lua 先形成完整结果再写输出，错误只返回固定文本。

公共配置和四家 DNS 的受限凭据同代存储。只允许当前候选中存在且服务商相同的 DNS 账户对应 key_id/secret/account_id/endpoint 四种槽，账户节名支持 64 字节及连字符，每槽 1～4096 字节，最多 128 槽。公共备份不带秘密；导入保留同服务商/同节名的已有凭据，删除账户或更换服务商后不复制旧凭据。旧代仍保留，回滚恢复目标代的配置及凭据。私钥、证书文件、ACME 私有账户和 URL 尚未迁移，此机制不等于完整敏感备份。

目录为当前 UID 的 0700，普通文件为 0600、单链接，拒绝符号链接和路径穿越。存储根只能显式指定 `/tmp/homegate-config-prototype-*` 下的私有目录；32 个代次含未发布遗留，达到上限明确拒绝。最大配置/凭据规模有界，但不是目标路由器资源测量；历史清理和生产保留期尚未实现。

## 确认与恢复

预览在独占 `flock -n` 下读取基线并生成差异和 128 位随机一次性句柄。私有计划绑定存储位置、完整基线清单（含凭据）、候选摘要、代次、启动标识和单调时钟五分钟有效期。摘要不返回 RPC/状态。替换、取消、任意配置或凭据更新、过期、启动标识变化、候选损坏、将计划复制到另一目录都会拒绝确认。测试 CLI 的 `can_commit=true` 只表示该隔离目录可提交，不改变生产 LuCI 的 `can_commit=false`。

新代完整校验后，依次对配置、祖先、清单、凭据文件、凭据目录及代目录调用检查返回值的 BusyBox `fsync`；对待切换的指针文件同步，再 rename 替换 `current`，最后同步存储目录。BusyBox 1.33.2 的 `sync -f` 不检查 `syncfs` 错误，因此未用它判断成功。切换前失败清理本次候选，保留原基线与计划；切换后目录同步失败返回代码 6 和 `Published pointer durability is uncertain`，不谎报成功，也不假称恢复旧状态。此时指针可能已切换，必须重新读状态/预览恢复，旧句柄不能重放。缺少 fsync 时拒绝提交。

回滚仅接受已提交祖先，复制目标为新代并同步后发布；未发布孤儿不可回滚。SIGKILL 后跳过已占用代号。消费者必须在同一锁下读同一代，不能分两次读取指针后拼接配置与凭据。

`/tmp` 在设备上通常是易失存储；文件/目录同步调用不使它跨重启保留。当前只验证同步顺序、进程异常和状态报告；生产持久位置、设备文件系统/断电测试、首次初始化恢复、旧 UCI/秘密迁移及业务应用失败恢复未完成。

## 隔离使用与测试

```sh
export HOMEGATE_CONFIG_PROTO_STORE="$(mktemp -d /tmp/homegate-config-prototype-XXXXXX)"
busybox ash project/core/prototype/homegate-config-prototype.sh --public-uci init
busybox ash project/core/prototype/homegate-config-prototype.sh --public-uci preview < public-backup
# 审查差异，使用本次返回的 confirmation；不在命令行放秘密。
busybox ash project/core/prototype/homegate-config-prototype.sh --public-uci commit CONFIRMATION
busybox ash project/core/prototype/homegate-config-prototype.sh --public-uci rollback-preview 1
```

新增依赖为 Lua 5.1 和 BusyBox fsync；目标虽有 Lua，fsync applet 仍待核实。CI 从已校验官方 BusyBox 1.33.2 构建，并从固定官方 UCI 提交 `415f9e48436d29f612348f58f546b3ad8d74ac38` 构建未修改的文本解析器/CLI（非 blob/Lua 库），核对实际 UCI 读取、引号、列表及恢复后的内容。源归档 SHA256：`4adce41d0f93e71f3564b8f4f7dd91c11d68da0a33b3f198a652d1312680a3d4`；这是主机解析互操作性测试，不是 QWRT 包编译或实机结果。

本地新增 4 项 Lua 适配器检查和既有 17 项公共解析、静态/工程检查通过。20 项真实 Linux 回归在 [本轮源码作业](https://github.com/frostcypress/HomeGate/actions/runs/38146374894)通过，源码提交 `9a1f8d0648820c84852ef4557c824bfc633a846d`。既有控制 10 项、旧事务 14 项、公共解析 17 项和页面/工程检查同时通过。SDK 三包构建与发布作业跳过。正常用例使用真实 BusyBox/Lua/文件/锁；故障用例仅替换 fsync/mv/cat 等外部边界以注入同步/进程/时钟故障，不模拟存储算法。详细验证记录仅本地保存。
