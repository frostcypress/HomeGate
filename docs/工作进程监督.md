# 隔离工作进程监督合同

1.3.0-r19 增加固定 Shell 监督器、独立会话看门进程和受限工作记录。工作端只读取私有配置帧并原子写入公共派生状态回执，不执行 DNS、ACME、代理、防火墙或服务命令；真实业务及开机/运行意图仍待接入。此阶段不安装到生产、不改旧 UCI，未完成 SDK/设备验收。

## 固定入口与私有传递

`homegate-worker-supervisor.sh run-apply <内部工作句柄>` 只能使用日志中的 applying 句柄。`recover` 无路径或命令参数，先确认旧工作族不可执行，再走 r18 的恢复和恢复 ACK。拒绝任意命令/路径参数；没有可配置工作端命令、测试钩子或 Web 路由。读取目标仍限定 `/tmp/homegate-config-prototype-*`。

监督器持有 `.recovery.lock` 与 `.supervisor.lock`，后者通过 FD 7 借给受信任内部协调子进程；匹配文件的设备/inode/权限后沿用同一 flock，其他描述符必须自行取得锁。工作记录存在时，配置引擎拒绝直接 ACK/恢复和普通写入，只允许正确句柄的工作端授权及私有快照。status 可报告 workers_pending，不返回句柄/摘要/PID。

启动使用私有 FIFO 门闩。先验证新会话、持久登记并同步 `worker` 文件，再发送 START。任何启动日志 fsync/rename/目录同步失败，都不能放行工作端。私有快照由同代配置引擎通过 FIFO 描述符写给 Lua 工作端；不进入普通文件、argv、公共 stdout 或日志。工作端输出及错误丢弃，公开响应只含固定元数据。

工作记录文件 0600、目录 0700，绑定格式、启动身份、存储路径摘要、监督器和看门进程 PID/start_time、模式、句柄与有界期限。拒绝错存储、异常行/数值/模式、符号或硬链接。该记录没有 MAC，不防 root 修改。默认期限 30 秒；隔离实验允许 HOMEGATE_WORKER_PROTO_TIMEOUT 为 1–30 秒，生产预算未冻结。

## 超时、停止与恢复

看门进程通过 setsid 成为独立会话/进程组首进程。它自行监视生产管道和工作端，TERM 一秒后向自己的进程组发送 KILL；目标始终是仍在运行的 `$$`，不向历史记录中的 PID 发信号。外层监督器遭 SIGKILL 后，看门期限仍生效；恢复入口可以在匹配启动/进程出生时间/会话/随机句柄后写入停止请求，由原看门进程停止自己的组。

回执必须匹配授权代次、apply/restore 模式及同代公共端口值。退出码 0 没有正确回执，或同组仍有可执行子进程，都不能 ACK。父监督器等待并核实整个工作组没有可执行成员，关闭并同步工作记录后，才调用应用或恢复 ACK。Zombie 不能继续执行，但不能把仍存活的组成员当作已清理。

应用端失败/超时后，只有已确认静默才能恢复基线并启动恢复端。恢复成功仍报告应用请求失败（退出码 8），避免把回滚伪装为应用成功；恢复端失败保留 restoring 屏障（退出码 7）。TERM/INT 等外层中断等待工作族停止后保留明确恢复需求。停止或归属无法证明时保持记录和屏障，返回错误，不猜测成功。

如果外层监督器和看门进程都遭 SIGKILL，且仍有活子进程，自动恢复失败关闭；恢复入口不会凭旧 PID 杀它们。PID/出生时间/随机句柄失配且原组仍活也如此。不同 boot 的旧记录不会向当前 PID 发信号。受限人工处理工具和目标设备的启动恢复尚未完成。

固定 Lua 回执工作端不会 fork/daemonize；快照生产端只使用同步子命令。未来实际依赖必须审计工作族归属，禁止未监督的 setsid/后台化逃逸。此版本没有 cgroup/subreaper，不能声称约束任意第三方命令或恢复所有双重强杀情形。

## 组件与验证

核对了 [BusyBox 官方接口](https://busybox.net/downloads/BusyBox.html) 的 setsid/stat，以及 [Linux proc 文档](https://www.kernel.org/doc/html/latest/filesystems/proc.html) 的 PID、进程组、会话和启动时间字段。CI 用固定官方 BusyBox 1.33.2 编译 setsid/sleep/mkfifo/ls/kill，并启用原生 ash 语法检查。目标 QWRT 的相关 applet、FIFO/锁/信号行为和资源峰值仍需实测。

tree-sitter-bash 0.25.1 不识别 POSIX `<>`。本地静态检查只将两个固定 FD 5/6 的该操作符等长替换为可解析的 `>>` 做 AST 审计；真实源码的 `sh -n`、`busybox ash -n` 和执行回归才验证实际读写 FIFO 语法，没有把掩码后的 AST 当作 Shell 执行通过。

新增 1 项静态安全/语法审计和 18 项真实 Linux 用例：正确回执、二进制秘密、应用失败、未读管道超时、恢复失败/重试、生产端失败、主动写入/ACK/恢复屏障、外层 TERM/SIGKILL、看门与监督器双重强杀失败关闭、失配 PID/句柄、旧 boot、安全路径、假成功回执、同组遗留子进程、启动日志两种同步失败、参数/期限边界。尚待本轮 Actions。业务只验证派生回执，不等于真实服务恢复。

监督仅用于隔离样机；/tmp 没有重启持久性承诺，没有真实 flash 断电结果，未测目标峰值。详细验证、当前三份 MD 和本地 ZIP 只保存在本地；生产写入口、凭据/证书树迁移、真实服务预检/恢复、SDK 三包及实机仍未完成。
