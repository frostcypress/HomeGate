# 生命周期持久基线初始化（阶段草稿）

1.3.0-r25 增加固定专用 `homegate-store-bootstrap-prototype.sh`。它只建立关闭状态的六类公共 schema 空基线、空凭据目录、HGSTORE1 身份、既有事务/监督锁及 HGBOOTSTRAP1 初始化回执；不是旧 UCI/秘密迁移，也不启停服务、不改旧配置、不安装生产核心。`bootstrap_enabled=false` 固定，环境和参数不能打开门禁，生产配方不安装原型。

命令仅接受 `bootstrap` 或 `resume`，目录固定 `/etc/homegate/transactions`，暂存目录固定在同一私有父目录下。必须由生命周期提前建立安全的共享 `frontend.lock`；本入口不补 runtime 锁、不替换现有锁、身份或目录权限。先持有共享 FD6，再建立 0700 父目录及阶段目录，所有文件 0600 单链接；清除可能影响 Lua 和安装路径的环境变量。网页持久操作仍不具备初始化权限。

初次初始化在独立阶段目录构建完整关闭基线，使用同一 Lua codec 规范化、已知文件哈希和严格路径/权限/行数检查。身份及初始化回执绑定最终固定路径与随机存储身份；摘要用于完整性而非认证。阶段包含隐藏文件在内的条目须精确匹配，凭据必须为空。检查和同步文件、代次目录、阶段目录及父目录后才整体 rename 发布，然后再次同步正式目录及父目录并由实际持久引擎检查。

任何失败或信号均保留现场，不递归删除或猜测恢复。初次命令发现暂存目录拒绝自动续做；显式 `resume` 只接受完整且可重新校验、同步的阶段，半成品需后续专门恢复工具处理。发布后目录同步不确定返回 6，正式目录保留；重新执行核对身份/回执、调用持久屏障并重新同步，不改变代次、凭据或锁 inode。重复执行也不重建已演进的合法存储。活动应用、孤立活动凭据或不安全元数据拒绝放行，初始化不能清除恢复屏障。

新增 3 项本地静态与 21 项 Linux 用例，覆盖真实引擎/17 原生入口、权限、重复执行、环境注入、锁竞争、显式恢复、阶段/身份损坏、隐藏条目、硬链接、同步失败和 SIGKILL。Linux 结果待当前 Actions。测试使用私有复制目录、路径/UID/固定门禁替换和已有 UCI/业务夹具，不能当作路由器、闪存或真实掉电验收。

**所有生产门禁保持关闭，没有三包。** 旧配置及秘密的受确认迁移、独立监督及孤立活动凭据协调、冷启动恢复、Go/其他生命周期写入口、新核心完整业务、SDK/ABI/设备资源仍待完成。当前完成的是空基线初始化机制草稿，不能称生产迁移完成或自行安装。

详细验证记录、当前三份接续 MD 和完整草稿 ZIP 仅本地保存；公开仓库只同步源码、概述和协议说明。
