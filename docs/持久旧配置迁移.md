# 固定来源的持久旧配置迁移副本

生命周期事务引擎增加 `--persistent migration-source-preview` 和 `--persistent migration-source-commit CONF`。`lifecycle_migration_enabled=false`，持久路径门禁也须开放才可执行；参数和环境不能打开门禁。生产配方仍不安装原型。这里只保存经确认的迁移副本，不切换旧服务或读取端。

固定来源为 `/etc/config/homegate`，不接收调用者路径或标准输入作为来源。要求 root 所有的普通单链接 0600 文件、安全父目录、有界大小；权限不合格直接拒绝，不自动 chmod。复用已建立的 `/etc/homegate/transactions`、存储身份、FD6 共享写锁、FD7 监督锁和事务锁。缺目录/锁、初始化待定、活动任务、应用恢复或 DNS 回执屏障均按既有规则拒绝，不创建运行锁、不清除历史证据。

预览只允许未改变的默认第一代及空凭据库。原文件以受限字节副本保存为候选 `legacy.conf`，捕获前后检查类型、所有者、权限、单链接、设备/inode/长度及完整 SHA；复用现有六类 UCI schema 和四家 DNS 私有字段映射，保留原始字段值，公共开关关闭。候选完整封存后检查文件/目录 fsync，并同步存储目录。确认计划使用既有格式的新固定枚举 `migration-source`，绑定基线、完整候选 manifest、boot 和五分钟期限；计划及其目录同步成功后才返回令牌。响应不包含私密值、私有路径、原始文件摘要或 manifest。

确认必须使用专用入口，普通 `commit`/应用入口不能提交这类计划，专用入口也不能提交普通导入计划。持久命名空间拒绝从 stdin 建立旧式 `migration-preview`，隔离实验模式保留原合同。再次核对候选及固定源字节；将公共配置、匹配凭据和原文件副本写入同一新代次，逐项同步。指针临时文件同步后、rename 前再核对来源，源内容或身份在检查期间变化时要求重新预览。令牌不能跨 boot、超时、重放或用于修改后的候选。

手工 UCI/其他 root 程序不参与 HomeGate 锁，最后一次检查后仍可能发生外部写入；本阶段不声称提供跨工具原子锁。源文件完全保留、旧读取端继续使用原字段，迁移副本不会被当成已切换生产配置。后续正式接管须停止受影响任务、接齐全部读写入口并在切换点重新核实来源。

提交前失败保留旧指针和可重新确认的预览；指针已发布而目录同步失败返回 6，保留完整新代次和原文件副本，不重放令牌。SIGKILL 留下的未完成事务仍由已有持久屏障拒绝自动放行。不会递归清理、自动续做迁移、删除旧秘密、复制任意证书路径、启停服务或发起网络请求。

成功报告明确 `migration_copied=true`、`legacy_source_retained=true`、`readers_switched=false`、`production_ready=false`。ACME 账户/证书树、运行锁生命周期初始化、完整业务读取端、官方授权确认界面及生产冷启动接管仍待完成。此副本机制不能替代目标 SDK、实际安装或实机掉电验证。

专项入口：`python3 scripts/持久旧配置迁移回归.py`；真实 Linux/BusyBox 执行增加 `--runtime`。测试只在复制的私有命名空间替换固定路径和源码门禁，详细结果仅保存在本地。
