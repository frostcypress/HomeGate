# 旧配置迁移候选与写入口接入合同

日期：2026-10-12。阶段：1.3.0-r16；生产切换未完成。

## 当前实现

同一 Shell 事务引擎增加 `--public-uci migration-preview`，从标准输入接收有界的旧 HomeGate UCI 文本，只允许原六类具名 section。可接收官方 `uci export homegate` 的 package 行。它只能作用于显式指定的 `/tmp/homegate-config-prototype-*` 实验目录，不能读取或删除生产 UCI 文件，生产配方不安装实验目录。

旧 DNS 的 `id` 映射为私有 `key_id`，`secret/account_id/endpoint` 原值保留；DDNS `url`、Web `target` 作为可能含认证的私有资源数据保存。空私有字段不分配文件，保留单引号、反斜杠和前后空格，不执行文本。DNS 四家绑定为 `provider.section.slot`；DDNS 为 `ddns.section.url`，Web 为 `web.section.target`。每文件最多 4096 字节，最多 192 个私有槽。普通 `certificate_mode/certificate_managed` 明确加入公共白名单，避免丢失既有 UI 管理语义；旧 certificate 的 domain 标量/列表映射为 domains，冲突或未知字段拒绝整份迁移，不静默遗漏。旧相对 DDNS host 按原核心 FullDomain 规则展开。公共备份导入仍拒绝原始含密钥 UCI，迁移解析器没有 Web 路由。

解析复用同一纯 Lua tokenizer、普通字段校验、跨 section 引用和规范化器；全部服务/访问总开关关闭。URL 数据只是私有保存，不代表业务 URL 合法或已能访问。ACME 私有账户、证书/私钥文件位于独立文件树，不在这份 UCI 文本中，尚未迁移。未知的路径字段也不会被当作授权读取任意文件。

## 确认与恢复

1. 迁移只允许从未改动的默认第一代、空凭据库开始。先在同一锁内分配未发布代次，保存原始 `legacy.conf`、公共候选和私有槽，验证 0700/0600、单链接、非符号链接、完整 manifest。
2. 输出的预览只含公共差异和一次性确认令牌。原始 UCI、副本、槽值、manifest 和摘要都不会输出。令牌同时绑定当前完整代次、启动 ID、五分钟期限、公共文本与候选完整 manifest。修改原始副本或私有槽后，即使重算候选 manifest，旧令牌仍失效。
3. 确认时重新验证候选，在新代次中一起复制公共配置、私有槽和原始副本；检查文件与目录 fsync，再原子切换 current。切换前失败保留当前代次和预览候选，可重试；切换后目录同步失败返回 exit 6 的不确定状态，保留已发布原始副本，不能重放令牌。
4. 暂存代次不是已提交祖先，不能作为恢复目标。取消/替换预览不激活服务；暂存副本仍留在私有目录，沿用最多 32 个代次的实验容量限制，没有自动清理或生产保留期。成功后可恢复原先公共配置和凭据代次；原始 UCI 副本仍保存在迁移历史代次中，不会因恢复或普通保存被删除。

这些机制只证明隔离目录的文件事务；`/tmp` 会在重启后丢失，fsync 不等于目标闪存断电验证。本轮 Linux 执行与官方 UCI 主机解析待回归；不是 SDK 或设备安装结果。

## 生产写入口盘点

| 写入口 | 当前行为与锁 | 生产接入要求 |
|---|---|---|
| Lua basic_apply、maintenance_apply | cursor set + finish_save；普通 UCI 保存/服务 reload | 在读取旧配置之前持有同一写锁；提交和应用纳入事务 |
| Lua public_account_apply、certificate_apply、public_apply、public_action | UCI 账户/凭据/规则写入，证书导入与删除、DNS 删除等副作用；部分直接 commit | 私有槽独立写入；普通配置和私有槽同代；远程删除不能靠本地回滚宣称撤销 |
| Lua wol_apply、wol_action | 主机增删、接口/last_wol_host；发送动作有直接 commit | 记忆字段共锁；发包结果与配置发布状态分开 |
| Lua access_delete_entry/rule/all | 名单读改写；调用 core 清理记录 | 共锁且基线一致；记录清理不是配置恢复的替代 |
| Lua config_reset、log_clear、access_update/clear_* | 重设配置/服务，日志/缓存操作 | reset 走整代事务；独立运行记录有自己的范围和锁 |
| Lua config_import/export、diagnostic_download | 已只预览/只读；导出不泄密 | 将来确认令牌须绑定官方授权会话；读接口不能变成任意命令/路径入口 |
| JS RPC 与 CLI web-submit/write jobs | Go 对照 frontend Engine 对 write 路由调用 Host.Begin，`/var/run/homegate/frontend.lock`；atomicConfig 写文件后 rename，失败恢复运行/启动意图 | 新实现复用一次锁边界，禁止内层重复获取形成死锁；原生 Lua 尚未共用这把锁 |
| Go 对照 config loader、daemon reload | UCI `id/secret/account_id/endpoint/url/target` 直接读取；Manager 仅内存快照锁 | 在删旧字段前迁移读取端，并验证全部 DNS/ACME/代理功能；本轮没有修改 Go 业务实现 |
| CLI cert-import/renew、ACME 账户、证书缓存、DDNS 状态、访问数据、防火墙与调度 | 各模块自己的文件/运行状态和生命周期，证书续期独立于 frontend 事务 | 明确配置代次引用和资源专用锁顺序；不能回滚整个文件树覆盖已完成续期 |
| init/hotplug、包 preinst/prerm/postinst/postrm、purge、独立旧安装脚本 | 服务/启动意图、UCI/升级暂存与数据树生命周期 | 升级/重装迁移恢复共锁，真正 FULL PURGE 单独合同；避免并发迁移和卸载 |
| 用户手工 UCI/其他插件 | 不参加 HomeGate 锁 | 发布前核对原配置指纹；检测变化则重新预览，不能覆盖外部修改 |

配置事务的锁覆盖顺序应是：官方授权后进入唯一协调器 → 获得配置写锁 → 读取并核对完整基线 → 生成候选并校验 → 发布 → 应用/记录应用失败 → 释放。前端与业务私有写接口都要调用同一入口；应用失败的补偿应有独立、限时恢复上下文，不能因请求超时被取消。远程 DNS 删除、发包和已完成续期不能假装可撤销。

当前没有把新实验锁硬塞给旧 Go/Lua 入口：旧读取端尚依赖 UCI 密钥，抢先删字段会破坏原业务。完成生产共锁、持久目录、全部读取端、文件树迁移和失败恢复之前，生产 LuCI 导入继续仅预览，migration_complete/release_ready 均为 false。
