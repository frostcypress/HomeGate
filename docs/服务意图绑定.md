# 服务开机/运行意图绑定合同

1.3.0-r20 为隔离事务增加 HGAPPLICATION2 日志，绑定配置代次与独立的开机启用、原运行状态及采样所在 boot。这里只实现受信任内部协调器交接协议：输入状态和完成观察值在回归中由夹具提供，没有读取实际 procd、调用 init start/stop/reload 或切换生产存储。不能把这层协议通过称为真实服务恢复通过。

## 绑定与授权

`--public-uci commit-apply-intent <确认句柄> <原开机启用0或1> <原运行0或1>` 使用已有预览/代次/凭据验证、锁和同步发布顺序。只允许字面 0/1，拒绝额外参数与任意命令。保存十一行 HGAPPLICATION2：格式、基线/目标代次、私有句柄、阶段、基线/目标绑定摘要、原开机启用、原运行、boot 身份，以及前十行的 SHA256。目录 0700、日志 0600 单链接；字段/阶段/句柄变化、错误终止换行或复制目录都会使验证失败。代次绑定摘要包含格式、存储目录、boot、两项原意图及清单；末行校验覆盖完整记录，均不是抵御 root 修改的 MAC。

记录在候选与凭据文件同步之后、current 发布之前同步落盘，首次日志 rename 可见后保留候选。prepared/applying/restoring/applied/restored 沿用既有写入屏障和恢复顺序，所有状态改写保留原意图；恢复不会从新配置、当前进程或开机链接重算基线。状态缺失不会默认为关闭，旧 HGAPPLICATION1 保持原回执实验协议，不能自动升级为服务事务。

`service-intent-read <内部句柄>` 仅在 applying/目标代次或 restoring/基线代次返回受限上下文：代次、阶段、原开机启用、原运行、期望运行及 same_boot。普通 status 仅增加 service_intent_bound；公共备份不包含服务记录、句柄或状态基线。`apply-service-snapshot-read` / `restore-service-snapshot-read` 通过原 FD3 私有管道读取对应代次的配置和二进制凭据，保持同一 flock 与句柄/阶段授权。HGAPPLICATION2 拒绝旧 apply-authorize 和旧回执工作端读取；HGAPPLICATION1 拒绝服务读取，避免跨协议误用。

## 应用、恢复与观察确认

目前只有禁用的导入/迁移/回滚候选。应用目标保留原开机链接意图，运行状态必须为 0；不因原开机启用就启动此前已停止的服务，也不激活导入配置。未来正常设置保存/显式启停的目标策略需要独立实现，不能沿用这一导入策略。

`apply-finish-intent <句柄> <观察开机启用0或1> <观察运行0或1>` 同时核对两项目标状态才登记 applied；`restore-finish-intent` 同时核对原开机启用和原运行才登记 restored。单项错误返回 7 且保留记录/屏障。HGAPPLICATION2 拒绝旧 success ACK；旧 `apply-finish <句柄> failure` 仍可保守登记 restoring 并恢复配置指针，此时 business_restored=false。仅发布/恢复指针都不代表服务完成。

boot 已变化时允许读取保存意图与保守恢复配置指针，但观察 ACK 返回 7，保留显式冷启动协调需求。尚未实现冷启动服务决策；不能把上次运行状态当成当前 procd 事实，也不能删除旧记录直接放行。applied/restored 已经过匹配观察 ACK 后，如清除日志失败，再次 recover-application 只重试收尾，不重新启动、停止或恢复旧意图。

内部调用者未来必须在共享写锁内真实采样开机链接与 procd 状态，在监督期限内执行固定预检/服务操作，再真实观察并等待旧工作族停止后 ACK。参数本身不是观测证据。本版没有此生产适配器、真实服务动作或 HGAPPLICATION2 工作监督接入，禁止从 Web 直接提供状态并提交。r19 监督器只适用 HGAPPLICATION1 回执，会拒绝此类服务日志。

## 验证范围

新增 16 项真实 Linux 回归覆盖四种独立状态、错观察/旧 ACK、私有同代快照、参数、旧日志兼容、字段/boot/链接/存储绑定、日志文件/目录同步失败、发布后 SIGKILL、两个终端清理失败、并发 ACK/重放、容量满及不同 boot 失败关闭。文件、flock、fsync、管道和进程终止是真实执行；服务状态和观察值是显式夹具，没有 actual procd/init 服务测试。当前新增 Linux 执行待 Actions，既有 r19 证据仅适用其历史提交。

详细记录、当前三份接续 MD 和本地 ZIP 仅保存在本地；完整新核心、生产共锁/持久路径、服务预检/启停/观察、实际 DNS/ACME/代理、防火墙、证书树、SDK/ABI/三包/实机仍未完成。没有设备掉电或目标资源峰值结论。
