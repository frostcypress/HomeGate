# 核心接口与迁移验收基线

日期：2026-10-11。这是对照源码整理的替换条件，不是新核心通过记录。目标为 Zyxel Armor G5 (NBG7815) 的 QWRT R26.3.8 / QSDK 12.5，Lua + IPK；musl/loader 与依赖信息已报告，具体 SDK 链接兼容尚未核实。用户明确重构基线为 1.3.0-10，作废优化版 1.3.1-1，不要求现在降级。所有下面的迁移验收项当前均为**未执行**。

## 可复用边界与选型原型

Shell 原型先验证 ash、curl、openssl、JSON/UCI 工具以及成熟 DNS/ACME/HTTPS 代理组件的实际能力。已有 curl/openssl 路径只说明工具存在，不能证明 TLS、签名算法、四家 DNS、DNS-01 或反向代理覆盖。nginx、ACME 客户端和 raw Ethernet WOL 组件需要单独查版本/功能/依赖。

对比的范围必须包括新增和已有组件的全部进程及子进程、私钥权限、配置事务和故障恢复。HTTPS 代理是持续服务，不能把任务脚本退出当作整个方案没有常驻占用。如果复用方案不能保留完整合同或满足实测预算，再提供 C 方案书面依据。当前 A/B 未冻结。

原型顺序：只读状态与配置校验 → 可隔离的 WOL → 四家 DNS 测试记录 → ACME staging → HTTPS 代理/访问控制 → 调度与防火墙恢复。公网变更、安装和卸载应在声明的测试对象上执行，记录其范围和回滚结果；状态采集脚本本身不执行这些操作。

## CLI 兼容入口

保留 `/usr/bin/homegate` 兼容入口。现行参数来自 `project/core/src/cmd/homegate/main.go` 的 switch，不能仅抄 usage（它遗漏 Web 桥接命令）。每个命令的字段与业务边界以对应模块及现有测试为准，完整机器清单见 `核心CLI合同.json`。

| 模块 | 参数合同 | 替换时必须验证 |
|---|---|---|
| 版本/诊断 | `version`、`selftest`、`status`、`recovery-status`、`check` | 真实进程/健康状态、错误码、版本一致性与恢复状态 |
| 网络 | `network-resolve` | 公网 IPv6、WAN6 未就绪、设备变更与地址撤销 |
| DNS 账户 | `dns-provider-catalog`、`dns-provider-status <account-id>`、`dns-zones <account-id>`、`dns-check-private <private-file>` | 四家认证/域名发现、受限请求文件、错误脱敏 |
| DDNS | `ddns-status`、`ddns-sync [rule-id]`、`ddns-delete <rule-id>` | AAAA 更新/无变化/删除、按规则隔离失败，DNS-01 记录独立 |
| CA/证书 | `acme-ca-catalog`、`acme-ca-status <ca> [environment]`、`cert-status`、`cert-renew [cert-id]`、`cert-import <cert-id> <cert-file> <key-file>` | 正式/测试环境分开、账户持久化、挑战清理、续期/本地导入校验 |
| 代理 | `proxy-status` | HTTPS/SNI/域名路由、上游访问、可信转发头重建、规则隔离 |
| 访问控制 | `access-status`、`access-update <region>`、`access-refresh <region>`、`access-recent`、`access-clear-all`、`access-clear-entry <ip> <host>`、`access-clear-denied`、`access-validate-file <path>` | 名单标准化、CN 数据完整性、更新/刷新语义、审计清理范围 |
| 日志 | `log-events [max-lines]` | 有界输出、过滤与脱敏；当前参数接受 1～20000，默认 1024；前端须另限字节 |
| 防火墙 | `firewall-status`、`firewall-apply`、`firewall-cleanup` | 仅处理插件规则、重复应用/清理幂等、启动失败分类与恢复 |
| 唤醒 | `wol-status`、`wol <host-id>`、`wol <interface> <mac>` | raw Ethernet + UDP、LAN 桥成员与发送计数；发送成功不冒充设备已启动 |
| 调度 | `daemon` | procd、停止清理、配置 HUP、网络 USR1、队列去重、旧任务不能回写新配置 |
| Web 桥接 | `web-read <request-file>`、`web-submit <request-file>`、`web-job <job-id>`、`web-job-status <job-id>`、`web-job-ack <job-id>` | Lua/JS 共用语义、异步真实状态、最小权限、队列与文件边界 |

JSON 公共 schema 当前为 `api_version=1`（`internal/api/schema.go`）。普通状态/动作常见字段 `ok/version/phase/error`，不是全部命令都返回完全相同结构。例如 version 返回 `api_version/version/arch`，不能强行用一个模板覆盖。新增字段可兼容扩展；删除/更改原字段必须同步消费者并提供明确迁移。

`status.service` 区分 configured/enabled/running/healthy，禁止只检查 PID 就写健康。WOL 返回 raw_sent/udp_sent/interfaces；Web 请求包含 route/form/write，结果包含模板数据、body、headers、redirect 或 error，任务状态包含 pending/job/result。字段基准见 `internal/status/status.go`、`internal/wol/report.go`、`internal/frontend/engine.go` 与 `jobs.go`。

## 配置、路由与安全合同

UCI 保留 homegate 包语义及 homegate/dns_account/ddns_rule/certificate/web_rule/wol_host section。业务字段、缺省值和校验见 `internal/config/config.go`；不得为了更换实现无声丢弃账户、规则、证书域名列表或 WOL 主机。秘密必须从普通 UCI 转移到受限存储，先完整备份再原子迁移；旧字段确认迁移成功才清除。失败应能恢复，缺秘密时不开启服务。

42 条现有 Web 路由及读写标签见 `internal/frontend/routes.json`。Lua/JS 的旧只读 URL 保留或明确重定向；RPC 写入要求授权，核心再校验输入。现行请求上限 2 MiB/4096 字段；私有文件为本进程所有、普通文件、无 group/other 权限；任务 ID 为 32 位小写十六进制。当前读/写超时为 18/180 秒。迁移若调整上限或超时，必须记录理由并回归浏览器及 rpcd 超时，不能默默放宽。

配置导出默认不含秘密，导入必须校验项目/格式/schema、预览差异、确认与持久回滚；恢复默认只处理本插件。升级/重装保留数据与原启停状态；原有真实卸载 FULL PURGE 是历史合同，改包名必须协调旧包脚本，防止把升级误认成卸载。见 `docs/历史接续_1.3.0-10.md` 和 `core/files`。

## 测量与 SDK 兼容关口

资源报告当前只提供一次容量快照，不是基准/峰值。测量记录 Swap、缓存和其他服务负载，计入复用组件新增占用；不能把 600932 KiB 可用 RAM 当作插件预算，也不能据此免做低占用优化。

SDK 如跨固件分支复用，先比对 ELF machine/loader、libc、动态库 SONAME/符号及依赖包名版本，再做小型用户态加载测试。不能从其他 SDK 安装内核模块去匹配 QWRT；LuCI 仍针对目标的 git-26.067.15087-09ae68b-1 验证，不由 SDK 年号推断前端能力。
