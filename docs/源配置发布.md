# 源配置绑定、发布与实际观察确认（草稿）

1.3.0-r22 增加 HGAPPLICATION3。它把固定来源 `/etc/config/homegate` 的私有原文件、公共候选、两代私有存储、启动意图和 boot 身份绑定到同一日志。新增 15 项 Linux 发布、2 项静态与全部既有回归通过[Actions](https://github.com/frostcypress/HomeGate/actions/runs/38332273913)，实际源码 `829e95aab10060da4920cb59bc8a836c15f32432`，41 个关键文件逐字节核对；SDK/发布跳过。

`commit-apply-projection CONF` 在配置锁、监督锁和现有 Go 桥接写锁 `/var/run/homegate/frontend.lock` 内采样服务，核对来源与已建立的基线。原始来源必须与基线公共配置及私有凭据完全相符；只有具有已绑定来源记录的基线才能接受上一轮发布的公共 UCI。来源原文件保存在候选代的 0600 `source.conf`，进入不可变清单与日志绑定，不进入导出、差异或状态。

`projection-publish HANDLE apply|restore` 只允许相应日志阶段和指针，要求实际服务停止且启动意图匹配。它检查固定配置仍为绑定的原文件或候选，先同步同目录的私有临时文件，再原子替换、同步文件与目录并读回摘要。遇到外部修改拒绝覆盖；替换后的同步失败保留待恢复日志。发布结果明确标记 `business_applied=false`。

`apply-finish-projection HANDLE` 与 `restore-finish-projection HANDLE` 没有成功标志或状态参数：在同一组写锁内核对已发布文件、执行两次实际服务采样并再次读回文件。应用确认要求运行状态为停止；恢复确认要求原来的运行状态，二者保留原启动意图。旧版传参确认不能关闭 HGAPPLICATION3。恢复先回退私有代指针，再发布绑定的原文件，随后核对配置与实际状态才关闭日志。证书文件不随此过程移动。

当前源码的 `production_writes_enabled=false` 是固定关闭常量，没有参数或环境变量开关；原型未安装进包。Linux 测试只在复制的原型中修改固定路径、UID 和这个常量，所有配置写入落在明确的私有夹具目录。官方 UCI 解析器、真实 fsync/rename、flock、Linux /proc 及进程用于回归；init/ubus 是明确夹具，启动和停止测试进程由测试程序完成，产品没有执行路由器服务启停。

生产门禁仍关闭的原因：原生 Lua 页面直接提交 UCI 的入口尚未统一进入同一事务锁；持久命名空间、自动建立生产迁移基线、受监督的固定启停与预检、冷启动协调和完整 Shell 新核心业务尚未完成。当前只处理安全导入的禁用候选；未来启用候选需要另行定义并验证应用意图，不能复用此处的停止期望。目标 QWRT 的 init/procd、jsonc/SDK ABI、BusyBox 功能、文件权限兼容和断电/资源峰值仍待实测。没有三包，不可安装本阶段草稿。

详细验证记录、当前三份接续 MD 和完整本地 ZIP 仅留本地；公开仓库只含源码、概述和协议文档。

本轮同时修正采样对无关短命进程退出的处理，并给 Linux 测试 daemon 增加 exec 就绪屏障。进程反复创建退出时仍执行四种启动/运行组合；被跟踪 PID 和已识别 HomeGate daemon 的身份变化继续拒绝，原有退出/重启回归保留。

固定 PID 列举改用 ash glob 和 printf，不依赖 BusyBox `ls` 对每个条目的 stat。列表仍验证固定命令退出码、64 KiB 和 4096 PID 上限，每个实际身份分别读取有界 `/proc` 数据。测试副本仅记录模块名与数字失败行号，不记录 PID、命令行、JSON 或凭据；该诊断不写入生产模块。

监督故障注入测试在强制终止监督者后，仅对短命元数据子进程仍持有恢复锁的“忙”响应进行最多两秒的重试，并逐次核对日志和配置指针未变；随后必须因活孤儿尚未静止而拒绝恢复。产品没有绕过锁或自动清除活工作记录。
