# 生命周期准备与迁移后的 Cloudflare 私有只读

本批连接运行目录/共享锁准备、持久空基线、固定来源旧配置迁移确认，以及既有 Cloudflare 私有读取协调器。生产配方仍不安装原型，所有生产门禁关闭，不替换旧核心或实际读取端。

固定内部入口为 `homegate-cloudflare-read.sh ACCOUNT --migrated`，只执行原有凭据检查的区域 GET，不接受 URL、路径、记录类型或调用者请求体。`dns_migrated_read_enabled=false`，原 DNS 读取与持久迁移门禁也须具备；环境不能启用。原有读取、分页、记录和恢复入口保持各自固定语义。

协调器取得 FD6/7 后，先检查原持久写入屏障，再调用 `--persistent migration-source-reader-check`。该检查要求当前代次含私有 `legacy.conf`，拒绝空基线、后续普通代次和含 `source.conf` 的投影代次；重新验证来源字节/权限/身份，并用同一 codec 从原始副本推导公共配置和全部匹配私有槽，核对当前代次。源文件手工改变、秘密不符、即使重算 manifest 的不一致代次都拒绝，不发送 HTTP。

父协调器从检查到私有快照、实际 curl 请求、独立监督结束保持 FD6/7，HomeGate 配置写入不能穿插改变代次。复用原有 HGPRIVATE1、固定系统 CA/HTTPS、curl 超时、有界响应、错误脱敏和工作目录收束，不增加第二套凭据读取或网络实现。手工 root/UCI 不参加锁，最后检查后的外部更改仍不能保证跨工具原子隔离；生产接管需统一所有入口并重新核实来源。

返回值使用原只读报告：实际配置代次、凭据检查结果和固定错误分类。不公开 Token、原始供应商错误、账户私有字段、来源路径或原始摘要；检查成功不代表旧服务已经改用私有存储、完整生命周期已接管或真实供应商已验收。没有网络写操作、自动凭据迁移、自动重试未知变更或放开生产门禁。

`scripts/生命周期业务集成回归.py --runtime` 使用实际 BusyBox、Lua、curl 7.83.1 与 loopback TLS 模拟服务，串联冷准备/确认/绑定读取，检查账户隔离、来源变化、锁与恢复屏障、错误脱敏及无状态发布。静态检查去掉 `--runtime`。专项不访问公网供应商或路由器；详细验证结果仅本地。活动工作流把本批三个相关专项加入同一轮集中源码检查，SDK/发布仍受既有门禁控制。
