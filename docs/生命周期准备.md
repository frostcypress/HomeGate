# 冷启动运行锁与持久基线准备

`homegate-lifecycle-prepare.sh prepare` 建立缺失的运行目录与共享锁，再持锁调用现有持久基线初始化器。`resume` 只请求原初始化器的显式恢复，不自动修复半成品。`runtime_prepare_enabled=false`，原持久初始化和事务门禁也仍关闭，生产配方不安装该工具。

命令只接受固定的 `prepare` 或 `resume`，要求 root，清除安装路径、Lua 注入与实验存储环境，使用固定 PATH。它不接受目录、钩子或命令参数。运行父目录必须已由系统建立；只接受物理 `/var/run`、`/run` 或 `/tmp/run`，兼容 `/var` 指向 `/tmp` 和 `/var/run` 指向 `/run` 的布局。解析后检查物理父目录为 root 所有、0700/0755；临时父目录须为 root 所有的 1777、0700 或 0755 普通目录。其他布局拒绝，实际固件布局仍需实机核实。

在已检查的物理父目录下，仅当 `homegate` 缺失时 mkdir 0700。已有目录须为普通非链接、root 所有的 0700，不 chmod、不替换。`frontend.lock` 缺失时用 noclobber 排他创建空 0600 文件；并发初始化失败的一方重新验证胜者的对象。已有锁必须是普通非链接、root 所有、0600、单链接且为空；不截断、删除或重建。不枚举清理目录中的其他对象。

此生命周期入口关闭继承的 FD6/7/8/9，打开自己的锁描述符，核对描述符与路径的设备/inode/权限绑定，然后非阻塞 flock，取得锁后再核对。旧写入者或并发准备持锁时返回 4，调用者可稍后明确重试；不把继承的锁当作内部借用通道。运行目录权限异常、硬/软链接、锁内容异常或检查中被替换均拒绝。

FD6 保持到持久初始化子进程及最后绑定检查结束。子进程复用既有共享锁描述符，按原初始化协议建立/检查身份、基线和持久屏障，不重复取得不同打开描述符导致自锁。子进程 2/4/6/7 原样分类传播，其他失败按 7；不输出子进程数据，不清除阶段文件或任何恢复屏障。失败时已创建的安全运行锁保留，下次准备使用同一个 inode。

运行锁属于易失运行状态；目录/锁存在只代表互斥对象存在，不代表配置迁移、服务健康或业务已启动。初始化器继续负责持久文件和目录的 fsync。成功报告仅为 `runtime_ready=true`、`baseline_ready=true`、`readers_switched=false`、`production_ready=false`。固定源迁移仍需独立预览和确认，旧 UCI 保留，不自动迁移证书树、启停守护进程、重试未知 DNS 操作或放开生产门禁。

专项使用复制的私有命名空间，可验证运行准备 → 持久空基线 → 固定源迁移确认 → 同代私有帧读取。该链路不包含真实供应商访问、完整调度或生产冷启动接管。Linux 中执行 `python3 scripts/生命周期准备回归.py --runtime`，静态检查去掉 `--runtime`；详细结果仅本地保留。
