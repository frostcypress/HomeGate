# 同代私有配置读取合同

1.3.0-r17 的隔离读取端与配置事务共用引擎和 flock；尚未安装到生产，也未把旧 DNS/ACME/代理读取切换到此接口。旧核心继续读取旧 UCI，密钥不能先删除。

`--public-uci snapshot-read` 不接受路径、账户或槽参数。调用方必须提供继承的 FD 3 管道，普通文件、终端和缺失描述符被拒绝。公共 stdout 只返回 API/代次/范围元数据，错误不含输入、秘密或秘密摘要。私有管道不得接到 Web RPC、日志或公开响应。

读取锁覆盖当前指针、完整代次/权限/清单校验和全部管道写入；读取配置、凭据不会分别取得不同代次。账户 provider 或资源类型/名称变化后，只读取当前代次匹配的槽。原迁移副本和其他历史凭据不进入快照，读操作不消耗待确认令牌。

二进制帧依次为 `HGPRIVATE1\n`、代次/公共字节数/槽数三个十进制换行字段、公共配置原始字节、每槽的名称长度/值长度和原始名称/值，最后 `END\n`。数值没有前导零；代次 1–32、公共配置至多 262144 字节、槽数至多 192、名称至多 96 字节、每值 1–4096 字节，总帧上限 1114112 字节。名称按字节严格递增，必须与同帧公共 schema 的 provider/账户或资源匹配。值可含 NUL 和非 UTF8，禁止以 JSON 或 Shell 变量转换。读取端只在完整 EOF 和所有校验成功后返回结果，部分帧不能用于业务。

编码器先验证完整帧再写入管道。传输失败返回通用错误；消费者丢失、被终止或无限期不读取仍需要上层受限执行器管理超时，当前隔离命令本身没有期限强杀机制。慢消费时配置写入返回 busy；这一点将纳入 Linux 执行回归。最大帧的 Lua 内存峰值和设备预算待实测，不能把字节上限当作已测内存峰值。

官方 [nixio 文件实现](https://raw.githubusercontent.com/openwrt/luci/master/libs/luci-lib-nixio/src/file.c) 的 `nixio_file_lock` 使用 `lockf`；不能直接替代现有 Go `syscall.Flock` 和 BusyBox `flock`。生产协调器需要统一相同锁机制并覆盖保存、凭据、服务操作和失败恢复后才能开放确认应用。此阶段没有宣称生产共锁、服务应用恢复、重启/断电或 SDK/实机验收。

6 项 Lua 解析检查覆盖二进制秘密、逐字节截断、尾随数据、跨账户/重复/乱序槽、数值及容量、私有/非规范公共配置、受限读取和错误反射。8 项 Linux 检查使用真实 BusyBox ash、flock、管道和文件，外部服务未执行。详细结果只保存在本地。
