# 组件复用核对

核对日期：2026-10-11。这里只确认官方源码/文档中的候选能力，没有在目标路由器安装组件，也没有冻结依赖。旧合同以 1.3.0-10 为准；不能为了复用组件改变用户账号类型或缩减功能。

| 候选 | 官方接口与旧合同核对 | 处理 |
|---|---|---|
| acme.sh dns_ali | Ali_Key/Ali_Secret，DNS-01 TXT 插件 | 账号类型可作为候选；尚不能替代 DDNS AAAA、zone 列表等完整 DNS 接口 |
| acme.sh dns_cf | CF_Token、CF_Account_ID/CF_Zone_ID | 可评估令牌认证；账号标识持久化、权限、日志/参数脱敏待验证 |
| acme.sh dns_tencent | Tencent_SecretId/Tencent_SecretKey，TC3 签名 | 与现行 DNSPod SecretId/SecretKey 方向一致；不能改用 dns_dp 的旧 DP_Id/DP_Key login_token |
| acme.sh dns_huaweicloud | HuaweiCloud_Username/Password/DomainName，IAM 令牌 | 与现行 AccessKey/SecretKey 签名认证不同；删除行为也需要逐条核对。需要兼容钩子或自有适配，不能直接替换 |
| nginx | HTTP proxy、WebSocket、访问名单有官方模块支持 | 只是候选能力；目标版本/编译模块、SNI、可信头、CN 名单、重载失败与峰值占用仍须逐项原型验证 |
| BusyBox 1.33.2 flock | 官方源码接受 -s/-x/-u/-n，没有 util-linux 的 -w | 隔离原型使用 -n 返回忙；真实设备 applet 行为待执行验证 |
| WOL 工具 | 旧核心同时有 raw Ethernet 与 UDP，包含接口绑定 | 单独 UDP 方案不足；raw 工具及桥成员行为尚未验证，不能宣布组件替代完成 |

acme.sh DNS 插件只解决证书挑战的一部分。HomeGate 的 DDNS、zone 发现、记录保留和错误合同要单独实现；DNSPod/Huawei 等认证不能根据服务名直接套插件。凭据需要独立受限存储，不能通过明文 argv 传入或被调试日志泄漏。

代理复用组件的全部进程内存、依赖存储与重载峰值都应计入插件预算。只有控制脚本较小不足以证明 Shell 方案满足标准。当前源码尚未引入这些第三方实现。
