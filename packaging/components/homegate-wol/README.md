# HomeGate 私有唤醒传输

项目 MIT 小型 C 组件，源代码和许可证随源码固定，不引入另一套核心。只安装 `/usr/libexec/homegate-wol/send`，不安装服务、不更改网络或防火墙、不增加 setuid/文件能力。需要现有 root/CAP_NET_RAW 权限；权限不足如实失败，不申请额外权限。

保留旧双路径：raw Ethernet 在所选接口及排序去重后的桥成员各发送3帧（EtherType 0x0842，广播目标，接口源MAC）；UDP 在所选接口绑定设备，向接口广播和255.255.255.255的9端口各发送3次。102字节Magic Packet包含6个FF和16次目标MAC；raw完整帧116字节。只将成功完整的sendto计数，部分成功可返回成功并保留失败路径警告；不声称设备已启动。

直接模式不依赖其他配置有效，保存主机模式读取受保护的配置快照。MAC支持六字节冒号/横线及Cisco分组点号输入；配置仍使用原共享codec的单播/重复检查。桥成员固定读取/sys/class/net，不接受调用者文件路径；最多1024成员，超量拒绝而不截断。C自身5秒警报及外层新会话6秒监督限制运行；中断/超时无有效完整回报时为未知，不伪造零发送，也不自动重发。

原生验证编译真实C组件，外部LD_PRELOAD夹具仅将socket/ioctl/sendto等替换为封闭捕获，不更改UID/GID/能力且不发送真实网络报文，永不打入安装包。报文内容、计数和失败验证不能代替目标接口、真实raw/UDP抓包与设备启动验收。目标组件从同SDK原生编译为独立依赖，不放入all架构核心包。工程三包仍只在实机前或必要构建验证时按需构建。
