DDNS 授权与任务

配置备份与恢复

导出的配置不包含秘密、证书私钥或运行授权。导入先预览差异，再使用下方确认应用；已有同标识秘密保留，缺少秘密的账户不能执行任务。回滚只可选择本配置库已提交的祖先代际，恢复对应的私有凭据，仍需预览确认。

复制现有 HomeGate 配置

先初始化独立配置，再预览复制现有 HomeGate 配置与秘密；仅可导入空的工程配置库。核对差异后点击“确认复制生产配置”。完整私有备份和原启用意图会保留，工程配置默认关闭；后续明确应用启用意图、授权规则，再启动调度。

复制不改变原 HomeGate 配置、服务或开机设置。需要原服务已建立的安全配置写锁；来源变化须重新预览。中断时按已返回的应用句柄续完，避免重复复制。

删除受管 AAAA

先停止并回收调度，再明确授权该规则。删除当前配置中该主机的全部 AAAA，不依赖 WAN 地址；不删除配置、其他主机或 TXT。结果未知时保留原证据，不能重复提交。

私有凭据

Cloudflare 使用 secret；其他提供商使用 key_id 和 secret，华为云还需 account_id。每次保存一个字段，值不会回显。账户配置变更须先确认，再保存凭据。

凭据保存后，请预览并确认发布当前配置，再重新明确授权。旧授权不会沿用。

ACME DNS-01 证书

    
先保存 DNS 账户和私有凭据，再预览并确认 ACME 证书配置。默认使用 Let’s Encrypt 测试环境；正式环境须在配置中明确选择。应用启用意图后手动签发，不要求 DDNS 规则写权。先停止 DDNS 调度；任务期间配置和凭据写入互斥。

    

    

    
    

    
明确启动后，每小时检查上方证书标识；未到期不下单、不新增任务。会话与手动签发及 DDNS 调度互斥，主开关禁用先停止会话。失败或未知结果停止本会话，重启后不自动重下订单；已知挑战可明确清理，未知写入按原恢复流程核对。收起会话不删除证书、账户、任务或回执。

    
任务最长15分钟；成功完成 TXT 清理并校验证书后才成对发布。预先存在的相同 TXT 不删除，其他 TXT 保持；未知写入保留原恢复屏障，不能重复下单或猜测清理。失败和中断不替换原证书。无开机、cron 或组件自动升级，不自动重载服务。

  

  
本地证书

    
先预览并确认本地证书配置。导入须证书未过期、已生效、私钥匹配，DNS SAN 与配置域名集合完全一致；域名之间用英文逗号分隔，通配符作为独立身份核对。此处保存材料，不自动重载服务；不检查公共 CA 信任链。

    

    

    

    

    

    
    
校验失败保留原证书对。修正材料前可明确取消候选；中断后续完会重新核对来源与材料。最多保留 16 个工程证书对历史，不替代生产证书目录。DNS-01 签发和定时续签见上方证书入口。

  

  
网站代理

    
先预览并确认规则，再保存私有上游地址并发布当前配置。应用启用意图后，明确选择规则启动；默认工程 HTTP / HTTPS 端口为 10080 / 10443。变更配置前先停止并收起会话。

    

    

    

    
    
证书发布后自动平滑重载，新连接核对通过后使用新证书，已有连接继续；候选失败保留旧证书并退避重试，旧证书失效时停止。当前支持 HTTP / HTTPS 上游和 WebSocket；HTTPS 上游须通过域名或 IP SAN、证书链及有效期校验。CN 放行需先取得有效双栈地址库；启动时冻结库快照，更新后重启会话采用新库。黑名单优先，手动白名单与 CN 可并用；IPv6 公网入口须另行明确应用防火墙；随后只恢复本次代理会话丢失的专属规则，停止时清理。状态不代表端到端健康检查。

  

  
网络唤醒
raw Ethernet 发到所选接口与桥成员，UDP 广播发到所选接口。计数只表示报文已提交发送，不代表设备已启动；部分路径失败会显示警告。直接发送可在其他配置不可用时独立执行。

    

    

    

    

    

  

  
工程 IPv6 公网入口
先启动工程代理，再明确应用入口。仅处理工程专属链，不修改生产 HomeGate 规则。内核规则状态须单独查看；清理失败会保留会话并阻止回收，处理后再重试。

  
访问管理

    

    
确认规则后，在网站代理中选择“仅手动白名单”启用限制；CN 与手动白名单命中任一即可放行，黑名单始终优先。“允许访问”仍执行黑名单。CN 表示 APNIC 登记分配网段，不是终端实时位置。

    
    
有效库7天内直接复用；下载在后台进行，主源失败尝试镜像。全文件记录总数、分类汇总和双栈网段验证通过后才发布；失败保留原库，无有效库时 CN 限制拒绝启动。代理运行中更新不改变当前快照，重启会话后生效。

    

    
最近64个来源与域名组合，重复访问合并计数；记录实际访问时的判断，不代表当前策略重评。仅在内存运行态保存，不记录请求路径、查询串、Token 或上游地址。观察采用尽力传递，过载可能丢失；清理不改变规则。未完成的长连接在结束时才产生记录。

  

  
主开关意图

    
应用启用意图不会代替规则授权，也不会自动启动。切换意图会撤销旧授权，启用后须重新明确授权规则。禁用会先请求合作停止；执行或恢复未完成时，待处理完毕后重试。

    
    
    
  

  
自动 DDNS 调度

    
先在 DDNS 页面明确授权规则，再选择持续运行或一次有界调度（最多15分钟、8批次）。持续运行按原节流执行；网络事件只唤醒当前会话，接口断开请求停止。不会开机自动启动、自动重开或自动清除未决写入。

    
    
    
    
    
    
停止需等待已进入的批次结束；配置变更前先停止并核对状态。有待核对的 DNS 写入时保留记录，不能回收绕过屏障。
