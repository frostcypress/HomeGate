# 原生生产路径候选部署

## r157 CLI补齐与旧Go包受控迁移（当前源码候选）

补齐dns-provider-status、dns-zones、dns-check-private、acme-ca-status、cert-renew、access-clear-entry、access-validate-file、log-events八个兼容入口。私有DNS接受原JSON请求或五行私有文件，沿既有四家只读签名/分页/监督模块，凭据只在受限文件和管道中流转，不写入配置、不授予运行权限。CA探测仅固定CA/环境的直连HTTPS GET，不跟随响应网址或重定向。指定证书沿原异步作业做同步观察，保留旧CLI十二分钟上限；聚合只选择当前源绑定任务范围中到期的证书，成功后不重复下单，未知结果返回真实任务并保留。名单文件校验和有界脱敏日志为只读；访问单项清理通过实际审计接收器，仅清除指定IP/主机，不改访问策略。

`scripts/native_transition.py --packages <已有原生三包目录> --output <新空目录>`只检查已有IPK并生成私有迁移工具集，不构建包、不连接设备。检查真实包名/版本/架构、逐文件安装字节/owner/权限、翻译字节和核心生命周期钩子，然后记录SHA。它拒绝r141工程包充当原生包。当前未产生真实r157原生包或迁移工具集交付物；源级回归使用明确标注的合成容器/外部opkg模型。

实际工具集采用固定目录/tmp/homegate-native-kit、root0700目录/0600文件。管理者明确调用`ash /tmp/homegate-native-kit/native-transition.sh prepare --confirm`后才操作旧安装：拒绝未处理旧Web任务或待清理标记，记录启用/运行意图、停止旧服务并按真实ELF inode核对退出；移走旧命令入口阻止新旧作业竞争，保护原配置inode，私有保留原安装钩子，再临时屏蔽本次受控换包涉及的旧prerm/postrm。数据根目录不搬走或清空，直接跨包名安装的preinst拒绝仍保留。

随后`install --confirm`只移除已记录的三个旧产品包，不强制移除其他依赖；再安装经过工具集SHA核对的原生三包，恢复原配置及启动链接意图。它不会自动授予DDNS权限或宣称旧运行状态已恢复：成功仍明确返回activation_pending，记录原运行意图，须在新原生页面预览接管/发布并确认任务及授权后启动。`recover --confirm`恢复受保护配置，旧核心仍安装时才恢复对应旧钩子/入口；新UI已部分安装时不把旧FULL PURGE钩子写回新包，不覆盖外部替换配置。恢复不伪称完成包回滚，也不自动重启服务。未恢复的hold或受保护配置会阻止原生包prerm/postrm清理；完成迁移/恢复后，真实FULL PURGE包含插件自己的/etc/.homegate-transition固定根，不留下旧钩子/入口。失败/停电保留阶段及恢复材料；目标opkg事务、overlay rename、依赖安装和实际旧版本兼容仍须包级验证。
