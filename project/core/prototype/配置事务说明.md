# 隔离配置事务与凭据存储

本文描述默认 `main-public-v1` 旧实验模式及其历史验证边界。1.3.0-r15 在同一引擎新增 `--public-uci` 六类配置模式，使用额外的确认绑定与 fsync 屏障，详见 [完整配置事务](../../../docs/完整配置事务.md)；不将旧模式的无 fsync 语义套用到新模式。

版本跟随根目录 VERSION/RELEASE。实验源码为 `homegate-config-prototype.sh`，生产配方不安装；不读写 `/etc/config/homegate`，不触发服务、网络或防火墙操作。它验证的是存储机制，还不能替换现有 UCI 导入。

## 使用与范围

显式指定 `/tmp/homegate-config-prototype-*` 下属于当前 UID 的 0700 目录；其下父目录也需 0700。文件均为 0600、单硬链接；路径不得有符号链接、`.` 或 `..`。互斥用真实 `flock -n`。需要 BusyBox ash、stat、expr、flock、head（含 `-c`）、sha256sum、cat、cp、mv、mkdir、rmdir、rm、id、dirname；目标 applet/构建选项仍需实机核实。

```sh
export HOMEGATE_CONFIG_PROTO_STORE="$(mktemp -d /tmp/homegate-config-prototype-XXXXXX)"
busybox ash project/core/prototype/homegate-config-prototype.sh init
busybox ash project/core/prototype/homegate-config-prototype.sh export > public.conf
busybox ash project/core/prototype/homegate-config-prototype.sh preview < public.conf
# 审查 changes，使用本次 preview 返回的 confirmation，不照抄固定值。
busybox ash project/core/prototype/homegate-config-prototype.sh commit CONFIRMATION
busybox ash project/core/prototype/homegate-config-prototype.sh status
busybox ash project/core/prototype/homegate-config-prototype.sh rollback-preview 1
```

`export` 是严格定序的实验格式：`homegate-prototype-config:1`、`slug=homegate`、`schema=main-public-v1` 三行头，再跟 enabled/access_enabled/auto_firewall、日志、DDNS 间隔、续期窗口和四个端口，共 11 个公共字段。只接受完整字段；拒绝未知/重复/乱序/越界、NUL 和不完整行。文件最多 1024 字节。数值规范化为十进制，恢复时 enabled/access_enabled 强制为 0。DNS 账户、规则、证书、代理、WOL 和原 UCI 备份格式尚未适配，不能把此格式当成完整配置备份。

凭据通过标准输入保存为不透明字节；不出现在 argv、导出、预览、状态、日志或错误中。调用只携带白名单服务商、账户内部节名（如 dns_a）和 key_id/secret/account_id/endpoint 槽名；实际服务商账户 ID 也只从标准输入写入 account_id 槽。每槽 1～4096 字节，最多 16 槽。这里的 provider 名称不代表已实现 DNS 请求或凭据内容校验。私钥与 ACME 账户存储另需实现。

```sh
# 输入文件应由授权调用方在私有目录准备；示例不把秘密直接写入命令。
busybox ash project/core/prototype/homegate-config-prototype.sh credential-put aliyun dns_a secret < private-input
busybox ash project/core/prototype/homegate-config-prototype.sh credential-delete aliyun dns_a secret
```

## 发布、确认与恢复

预览写入一个原子替换的私有计划文件，包含当前代次、随机句柄、操作和规范化候选。随机性来自读取 `/dev/urandom` 的 16 字节，检查完整读取后经 SHA256 取 128 位确认句柄。预览展示公共字段的真实差异；未提交前当前配置不变。第二次预览覆盖前一次，cancel 撤销；任意成功配置/凭据更新都会使旧句柄失效。

每次提交先创建新代目录，复制公共配置和受限凭据，生成并核对完整性清单，最后通过一次 rename 替换 `current` 指针。消费者只能在同一把锁下从 current 指向的同一代读取两者，不能拼用不同代。回滚仅接受已提交祖先，复制目标公共配置和凭据为新代，仍保持服务关闭；确认句柄不得重放。输入或完整性清单永不被 eval/source，校验只对已检查的固定文件名计算哈希，拒绝清单中的任意路径读取。

普通写入失败删除本次已分配的候选文件，保持旧 current 和计划，可重试。SIGKILL 可留下未发布代和临时文件；后续更新跳过已占用代号，未发布代不可作为回滚目标。最多分配 32 代（含崩溃遗留）和 32 个有界临时文件，容量达到后明确拒绝，不自动删除恢复材料。历史凭据会保留在私有代目录中；生产版本仍需明确保留期、垃圾清理和完全卸载规则。

## 验证边界

1 项本地语法/隔离检查已通过。14 项 Linux 用例覆盖真实文件/锁、预览差异、一次性确认、凭据遗漏、边界、回滚、权限/链接/损坏、并发、写入故障、SIGKILL、容量、随机源短读和预览基线读取失败。首轮 13 项已通过；补充错误处理后完整 14 项已通过 [本轮运行](https://github.com/frostcypress/HomeGate/actions/runs/38138863941)。只有故障用例替换 mv/head 注入故障，正常用例全用真实 BusyBox；不模拟存储算法。

存储根目录在 `/tmp`，没有 fsync 或目录同步；rename 只验证进程异常下的原子可见性，**没有断电/重启持久性保证**。SIGKILL 打断首次初始化时可能需要人工恢复该私有实验目录。生产持久备份、UCI/完整业务 schema、服务端 LuCI 授权/预览界面、秘密迁移、业务检查和应用失败自动回滚均未接入，不据此标记完整配置事务已完成。
